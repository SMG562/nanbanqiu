# 0002 登录只保留手机号

- 状态：已接受
- 日期：2026-11-02　· 拍板：所有者

## 背景
需要决定登录入口。数据库里 `users.phone_e164` 是唯一必填，加入口会牵动库结构，并可能出现一人多号。

## 决定
只做手机号 + 短信验证码登录，不做邮箱、Google。登录页写明「手机号只用于登录验证，不会显示给其他球友」。

## 否决的方案
- 邮箱登录：取验证码要切换应用，会劝退人。
- Google 一键登录：暂不做；要加得改库，且会出现一人多号。

## 后果
- 好处：短信验证码在手机键盘上一键填入，最顺；库结构不变。
- 代价：依赖短信发件人登记（Vonage 工单进行中）；有人不愿留手机号。

## 什么情况下回头重看
登录漏斗数据出来后，出现任一情况再考虑加 Google 一键登录：到「手机号」这一步流失明显 · 内测有 2–3 人明说不想留手机号 · 收不到验证码的反馈反复出现。
