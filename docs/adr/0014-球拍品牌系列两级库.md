# 0014 球拍库改为「品牌 → 系列」两级（部分取代 0009）

- 状态：已接受
- 日期：2026-11-18　· 拍板：所有者 SMG562（#60 11-18 第 2 条及 03:03 答复）
- 相关：#377（PR1 数据层）· ADR 0009（旧 `racket_catalog`）· ADR 0013（接口只加不改）

## 决定
1. 新增 `brands` / `racket_series`（每牌一条 `is_other`「其他系列」）/ `racket_aliases` / `catalogue_submissions`；前台全拒，只走 SECURITY DEFINER 函数。
2. `user_rackets` 加 `brand_id / series_id / other_text / other_brand_text / nickname(≤12 字符)`；`series_id` 与 `other_text` 二选一；排序沿用 `slot`（1=主力，规格里的 sort=0）。
3. 旧 `racket_catalog`、旧列 `brand / series / catalog_id`、`api_player_rackets` 原样保留（ADR 0013，删除另走迁移，PR3 之后）；新结构读取用新增的 `api_player_rackets2`。`api_set_rackets` 新旧形状都收，旧形状尽量映射到新列。
4. 没有隐私字段：球拍默认公开，不做隐私开关（所有者 11-18 答复）。
5. 种子先逐字拷贝旧 catalog；别名由所有者补。规格里的拼写（HEAD / PERCEPT / TFight）11-18 定为沿用迁移现写法（MDD1102 决定，所有者 SMG562 确认为 #60 第 2 条的核实结论），不另提种子文件。

## 取代范围
只取代 ADR 0009 里「单层产品库」的结构；其统计（`racket_daily`、`racket_rollup`）与埋点不变。
