# NNNN 标题（一句话说清决定）

- 状态：待定 / 已接受 / 已取代（被 NNNN）/ 已废弃
- 日期：2026-MM-DD　· 拍板：（谁）
- 相关：Issue / PR / 其他 ADR

## 背景
遇到什么问题、有什么约束。只写事实。

## 决定
我们做什么（一两句话，不留歧义）。

## 否决的方案
- 方案 A：为什么不选
- 方案 B：为什么不选

## 后果
好处；代价；以后哪些事因此变得容易 / 困难。

## 什么情况下回头重看
写出具体触发条件（例如某个数据出现、某个服务价格变化），避免「永远不能改」或「随时能改」。

## 来源
决定记录在哪里（进度记录 / 提交 / Issue 链接）。
