# 0015 场边照片存放在 Cloudflare R2，经本站接口发放短时签名地址

- 状态：已接受
- 日期：2026-11-18　· 拍板：所有者 SMG562（对比后选 R2；其余方案条款同意，见 #393）
- 相关：Issue #393（方案与 PR 拆分）· #369 · #372 · ADR 0005（正式库在悉尼）· ADR 0013（接口只加不改）

## 背景
场边以图片为主，一期要做图片发布。数据库已有 `sb_photos`（只存键）与发布校验，缺对象存储。候选：Cloudflare R2、Supabase Storage（我们已在用 Supabase 悉尼库）。

## 决定
1. 照片原图 / 缩略 / 极小图三个文件放 **Cloudflare R2**，正式与测试各一个桶（位置提示 `oc`），Worker / Pages Function 用**绑定**读写，不使用任何长期密钥。
2. 前台只和本站 `/api/sideline/photos…` 打交道：上传校验（JPEG、无 EXIF、大小 / 像素上限、本人前缀）、读取用 HMAC 签名的短时地址；R2 不开公共域名。
3. 存储访问收在一个小适配层（put / get / delete / list），日后换 Supabase Storage 或任何 S3 兼容服务只改这一个文件。

## 为什么是 R2（对本项目起决定作用的几点）
| 维度 | R2 | Supabase Storage |
|---|---|---|
| 接入密钥 | Worker 绑定到指定桶，没有可外泄的凭证 | 从 Worker 写入要用 service_role 密钥，权限等于绕过行级权限的整库管理员，一旦泄露不止照片 |
| 登录令牌 | 我们的接口已验两种令牌（Supabase 令牌 + 登录交接自签令牌）；R2 不看令牌，身份由接口决定 | Storage 的行级权限只认 Supabase 令牌，登录交接令牌进不去；只能再走接口 + 管理员密钥，等于没用上它的权限模型 |
| 出站流量 | 免费 | 与数据库等共用一份额度，超出后按量收费；图片是最吃流量的东西 |
| 图片处理 | 不需要：客户端已生成三个变体 | 在线缩放按「原图张数」另收费，我们同样用不上 |
| 审核 / 清理任务 | 定时任务（notify-worker）用同一平台的绑定直接读写，不走公网 | 要经 HTTPS 下载每张图再识别 |
| 区域 | 位置提示 `oc` 是尽力而为，不保证；读图靠 Cloudflare 边缘缓存，在澳洲就近 | 悉尼项目，区域明确（ADR 0005 的好处） |
| 新增依赖 | 同一家平台的新产品（需在账号里启用 R2，可能要绑定付款方式） | 无新增服务商 |

成本（以官网为准，写进 L10 表）：R2 标准存储每 GB 每月 0.015 美元，写 / 列 每百万次 4.5 美元，读 每百万次 0.36 美元，每月含 10 GB、100 万次写、1000 万次读，出站免费。Supabase 免费版 1 GB 存储 / 5 GB 出站，Pro 含 100 GB 存储 / 250 GB 出站（全库共用），超出出站 0.09 美元 / GB。**一期用量下两边花费都接近 0，不是决定因素；决定因素是上表前两行（密钥与登录模型）和照片的出站流量会随用户增长。**

## 否决的方案
- Supabase Storage：区域最明确，但按上表需要把整库管理员密钥放进 Worker，且登录交接令牌用不了它的权限；出站流量与数据库共用额度。
- 浏览器直传 R2（预签名 PUT）：绕过我们的校验（EXIF、魔数、像素、频率），做不到「拒收含位置信息的文件」，否决；上传一律经本站接口（图片已压到 ≤1.5 MB，远低于 Worker 请求体上限）。
- R2 公共域名直读：无法做到「过 24 小时仅本人可见」「打码 / 下架即时生效」，否决。

## 后果
- 好处：没有新密钥；出站免费；审核和清理任务同平台；签名地址 + 边缘缓存不必每张图查库。
- 代价：多一个要核对的服务（L10）；区域是提示不是保证（隐私清单 / privacy.html 写法按「优先存放在大洋洲区域的数据中心」，不写「保证在澳洲」）；预览 / 正式、Pages / Workers 的绑定要分别配好（P0 spike 先验）。
- 需要同时做：每小时清理孤儿与已删图片；账号注销清理；`photos_paused` 一键停传。

## 什么情况下回头重看
- P0 spike 发现 R2 绑定在我们的部署方式下不可用。
- 隐私评估认定必须保证数据只在澳洲（那时换 Supabase 悉尼 Storage，改适配层一个文件）。
- 月账单里照片相关超过 50 美元，或 R2 价格 / 条款变化。
