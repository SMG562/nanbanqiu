# 0003 先只做澳洲城市，一城一网址，分享保持短链接

- 状态：已接受
- 日期：2026-10-22　· 拍板：所有者

## 背景
设计里有国内与澳洲多城市扩展；需要定范围和网址方案。

## 决定
- 先不做国内，只把澳洲几个城市做好；设计里的国内部分保留为将来的清单。
- 区、球场、球局、邀约、用户都带城市（球场的城市由所在区决定）。
- 现在只显示墨尔本，不做城市切换；上线后每个城市一个网址（nanbanqiu.com/melbourne、/sydney……）。
- 分享保持短链接 `/g/码`、`/p/编号`，由后端跳到对应城市；不带城市的域名默认墨尔本；打开尚未开放的城市显示「悉尼即将开放」并可登记开放通知。
- 设计稿里「顶部切换城市」取消。

## 后果
- 好处：范围收窄；各城市数据与网址清晰分开。
- 代价：数据模型都带城市字段，新表要考虑城市归属。

## 什么情况下回头重看
决定启动国内市场，或需要同一用户跨城使用。
