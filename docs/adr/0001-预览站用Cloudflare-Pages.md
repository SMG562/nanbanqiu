# 0001 预览站用 Cloudflare Pages，推送到 main 自动部署

- 状态：已接受
- 日期：2026-10-27　· 拍板：所有者

## 背景
仓库是私有的，需要一个随推送自动更新的预览网站，不再手动发布预览页。

## 决定
预览站放 Cloudflare Pages（`nanbanqiu-preview.pages.dev`），推送到 main 自动部署；构建 `node tools/site.mjs` → `site/`，只放三个页面、隐私、条款、安装配置和入口页，并禁止搜索引擎收录、不缓存。要公开的新文件写进 `site.mjs` 白名单。

## 否决的方案
- GitHub Pages：私有仓库使用它要付费套餐。

## 后果
- 好处：推送即更新；分支预览自动出现（后来用于连测试库，见 0007）。
- 代价：部署配置（`wrangler.jsonc`）改动有风险，必须先在分支上试。

## 什么情况下回头重看
仓库改为公开、或 Cloudflare 的套餐 / 价格 / 限制变化。
