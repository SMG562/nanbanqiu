# 0011 生成文件不再提交进 main

- 状态：**已接受**（11-11 所有者授权「按最佳实践处理」）；阶段 ① 在 PR `adr-0011-no-generated-files`，②③ 见「分步」
- 日期：2026-11-10 提出 · 2026-11-11 接受并实现阶段 ①
- 相关：Issue #152（第 5 级）· PR #151（用 `.gitattributes` 缓解）· ADR 0010

## 背景
`南伴球_PWA.html` / `南伴球_Web.html` / `南伴球_后台.html`（由 `src/` 拼出）、`server/migrations/_bundle.sql`（由迁移拼出）、`schema.sql`（手工与迁移同步）都提交在仓库里。多人并行开发时，这些文件每个 PR 都会改，必然冲突。#151 让合并时先留一边、合并后重新生成，冲突不再要人处理，但每个 PR 的 diff 里仍有几千行生成内容，评审要绕开它们，仓库体积也在涨（四个文件合计约 2.9MB，每次改动都整份入历史）。

## 决定（行业通行做法：构建产物不进版本库，由 CI / 部署现生成）
1. **三个 HTML + `_bundle.sql` 不再提交**：写进 `.gitignore`，仓库里不再跟踪。
2. **在三个入口现生成**（都只调用已有的 `tools/build.mjs`、`tools/migrate_bundle.mjs`，没有新脚本）：
   - `tests/run_all.mjs` 开跑时（本地、`tests-fast`、`tests`、`visual-baseline` 都走它）；
   - `tools/site.mjs` 开头——Cloudflare Pages 的构建命令本来就是 `node tools/site.mjs`，所以**不需要改 Cloudflare 后台设置**；拼不出来就构建失败，不会发布旧版；
   - 手动：`node tools/build.mjs`（要用浏览器直接打开 HTML 的人）。
3. **合并规则瘦身**：生成文件没了，`.gitattributes` 只留 `src/*.list` 的 union；`merge=nbq-generated` 驱动、`.githooks/post-merge` 钩子和 `setup_env.sh` 里的驱动配置一并删除。
4. **CI 触发改靠 `src/**`**：以前改 `.css` / `.list` 靠生成的 HTML 一起变才触发测试；HTML 不入库后，两份工作流的 `paths` 加 `src/**`（`unit/ci_paths` 盯着）。
5. **新增机器检查**：`static/build` 断言这四个文件没被 git 跟踪、且在 `.gitignore` 里，防止有人又提交回去。

## 已验证（阶段 ①）
- 清空磁盘上的四个文件 → `run_all` 自动生成 → 静态 + 相关单元测试全过。
- 生成结果与 main 上原先提交的版本**逐字节相同**（三个 HTML + `_bundle.sql`）。
- 单独跑 `node tools/site.mjs`（= Pages 构建命令）：自己生成 HTML 再发布，`site/pwa.html` 与原版逐字节相同。
- 分支预览站（Cloudflare 真实构建）核对见 PR 描述。

## 代价与取舍
- 直接用浏览器打开 HTML 的人要先 `node tools/build.mjs` 一次；单个测试脚本绕过 `run_all` 直接 `node` 跑时同理（写进 开发规矩 / tests/README / CONTRIBUTING）。
- `sync_files.sh` 同步到电脑文件夹的内容不再含这些生成文件（电脑上已有的旧副本不会被删，也不会再更新）；看页面用预览站。
- Pages 构建现在多依赖 `src/` 完整和 node 可用（原本就依赖 node 跑 `site.mjs`）。
- 回退：把四个文件重新提交、去掉 `.gitignore` 里的四行、还原 `.gitattributes` / 钩子即可（revert 这个 PR）。

## 分步
- ① 三个 HTML + `_bundle.sql`（本 PR，草稿 → 预览站核对 → 所有者点头合并）。
- ② 合并后观察一周：看 `merge-conflict` 次数是否下降（`handoff_check` / 周报）。
- ③ `schema.sql`：由迁移在空库执行后导出（新增 `tools/schema_dump.mjs`），导出结果必须与 `db-parity` 的结构指纹逐项一致，否则保持手工；**单独的 PR 和单独的决定**，本 ADR 不含。
