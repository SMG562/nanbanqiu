# 0012 运营模式 v2：做减法（只有不可逆的事要第二双眼）

- 状态：已接受
- 日期：2026-11-13　· 拍板：所有者 SMG562（11-13 11:55 墨尔本，「我都同意……往后都不再发生」）
- 相关：Issue #214 #229 #240 · ADR 0010 · 项目文档 `减法方案_运营模式v2_2026-11-13.md`

## 背景
11-13 实查：开着 15 个 PR（8 个在改流程本身）、83 个 Issue、64 个脚本、12 个工作流；14 天合并 99 个 PR，其中 73 个提交只是「合并 main」；公告 5 条、定时巡检每天 5 次；上线清单（短信发件人、删测试号、球场核对、回滚演练）没人推。2–3 人在用 30 人的流程，且每次出事就补规矩、没人删。

## 决定
1. **一个目标**：上线。路线图只看「上线前」标签的 Issue（总览 #53）；每周每人最多 3 件。流程优化不排期，除非它在拖慢上线。
2. **在制品总数 ≤ 3**（非草稿 PR，两人合计）；草稿超两周没动就关。
3. **4 类不可逆的事要第二双眼**：①正式库迁移 / 结构 ②登录、密钥、权限、CODEOWNERS ③部署与对外发布 ④删除数据 / 文件。其余 CI 全绿后自己合，每周抽查 3 个（`spot_check.mjs`）。
4. **独立复核范围收窄**：只留公共层（0130 0140 0155 0495）、`server/api|admin`、`functions/`、迁移与 `schema.sql`、测试运行器（#185）。`tools/` `.github/` `.claude/skills/` 改为自助 + CI + 抽查（红线文件仍由所有者 / 共同所有者合）。
5. **规矩只增不减的机器守卫**：`tests/spec/doc_budget.json` 里文档字节、`tools` 脚本数（≤58）、工作流数（≤13）都只降不升；新增先删。每月 30 分钟删「这个月没拦过事」的规则。
6. **沟通只两处**：周报 Issue（周一：上周完成 / 卡在哪 / 本周最多 3 件）与具体 PR。公告只在规则变化时发、≤ 5 行；不再发更正串。提案 Issue 只在「出过真实事故 + 有数字」时才开。
7. **省 token**：一个会话一件事；复核子会话只用于第 4 条范围；定时巡检从每天 5 次降到 2 次；订阅 PR 一次 ≤ 2 个。
8. **看四个结果数字**（DORA）：部署频率、变更前置时间、变更失败率、恢复时间；另看开着的 PR 数、非草稿数、流程类 PR 占比（目标 ≤ 20%）。一周后回看。

## 后果
- 好处：等待从「复核队列」降到「CI 时间」；PR / Issue 数量可控；所有者回到上线清单。
- 代价：`tools/`、`.github/` 的错误更多靠 CI 和抽查发现；若一个月内同类错误第二次出现，把对应路径加回复核范围。
- 回退：把 `tools/decision_card.mjs` 的 REVIEW 加回路径即可。

## 否决的方案
- 全部取消复核：公共层与迁移出错面大、难回退。
- 维持现状：流程件数只增不减，上线被挤到后面。

## 补充 11-13 14:43：常设授权（所有者原话「我都同意……最好减少问我，需要我审批同意 approval 的情况」）
1. **只有第 3 条的 4 类单向门问所有者**：正式库迁移 / 结构、登录 / 密钥 / 权限 / CODEOWNERS、部署与对外发布、删除数据 / 文件。其余一律不问。
2. **红线文件里的流程类改动**（`tools/` 合并 / 闸门脚本、`.github/` 工作流、看板、文档）由 AI 会话自行合并，条件：`pr_merge.sh --check` 全 ✅（含「其他 PR 检查没有红的」）+ 单测 + 有事故或变异证据 + 不落在 4 类单向门；合并后 `gate.sh` 复核，红了立刻 revert 并在 #216 留一行。
3. **GitHub Approve 不是闸门**，不等、不对头提交（#233 活锁教训）。共同所有者（`.github/CO_OWNERS`）的红线 PR 自己合。
4. **auto-merge 转正自动化**：影子运行（collab-board 的 shadow job，11-13 起）满一周、与 `pr_merge.sh` 一致率 ≥ 95%，由定时任务把 `merge-gate` 等设为必需检查并对非红线 PR 开 auto-merge；一致率不够就只报数、不转正。回退：删必需检查、关 auto-merge。
5. 仓库是 User 账号，没有原生合并队列；用 auto-merge + 必需检查近似。仓库改回私有则整套失效，先定可见性。
