# 前端风格（设计令牌、标尺、无障碍、设计债）

对标 Apple HIG：**内容优先、克制、层次清楚**。南伴球的落地：页面是约球的工具，不抢戏；品牌绿是主色，荧光黄绿（球）是整屏唯一的亮点；信息靠字重和留白分层，不靠装饰。
这份文档和 CSS 由测试 `tests/unit/design_tokens.mjs` 对账：令牌表写错或漏写、设计债变多、对比度变差，CI 直接红。**跟踪与分步计划：Issue #322。**

## 3. 平台规则（每条都踩过或有现成实现）
1. **安全区**：贴边的东西（顶栏、底栏、贴底输入栏）用 `--sb` / `--hb`（手机版）；网页版目前没有安全区处理（#322 第 3 步）。
2. **键盘 / 弹层高度只来自可视区**，不用 `vh` / `svh` / 固定 `min-height`（11-16 聊天输入栏根因，详见 `.claude/skills/frontend-state-ui-consistency/SKILL.md` §九、§十一）。
3. **减少动效**：所有循环 / 大位移动画必须有 `prefers-reduced-motion` 分支（现手机 5 处、网页 4 处，测试保底不许少）。
4. **焦点**：键盘 / 外接键盘可达的元素用 `:focus-visible` 显示焦点环，不写 `outline:none` 而不补替代样式（保底次数同样由测试守着）。
5. **微信内置浏览器**顶栏用 `--wx`，不写死 44px。
6. **没有真实数据的数字不显示**（想打人数、附近有人），空状态用小毛 + 一句话（`.claude/skills/nanbanqiu-empty-state-ux/SKILL.md`）。

## 4. 对比度（WCAG 2.x，正文要 ≥ 4.5:1；11-17 实测，测试保底）
| 组合 | 比值 | 结论 |
|---|---|---|
| `--ink` / 页面底 | 14.1 | ✓ |
| `--ink2` / 白 | 8.4 | ✓ |
| `--g` / 白，白 / `--g` | 6.47 | ✓ |
| `--red` / 白 | 4.57 | ✓（刚过线） |
| `--ink` / `--lime` | 12.88 | ✓ 荧光黄绿上只放深色字 |
| `--mut` / 白 | 5.43 | ✓ |
| `--mut` / 页面底 | 4.9 | ✓ |
| `--dim` / 白 | 3.65 | ✓ 非文本 3:1（仅图标 / 禁用，不得放必读文字） |
| `--blue` / 白 | 3.87 | ✗ 欠账：只可用于大字（≥ 18.66px 粗体或 ≥ 24px）/ 图标 |
| `--lime` / 白 | 1.38 | ✗ 设计上就不能做文字 |

写死的 `#8A928A`、`#9AA29B` 等偏淡手写灰已清零（11-17，#322 第 1 步 PR-B1），统一走 `--mut` / `--dim`。**新写的必读文字不得用低于 4.5:1 的组合。** 分享图（`.wxcard` `.ogA` `.ogL`，导出成图片）有自己的配色，列入第 6 步。

**场边页**是独立的 Shadow DOM（样式在 `src/shared/side/0010-开头.js`），页面底 `--bg`、文字角色 `--ink / --ink2 / --mut / --dim`、强调色 `--acc`（= 品牌绿 `--g`）都与主站**同值**，由测试守；不再有自己的稿纸色和场边绿。场边里的插画 / 照片占位色另算（第 6 步）。

## 5. 设计债与收敛规则（棘轮：只降不升）
| 手机版 / 网页版 | 现状（11-17） | 目标 |
|---|---|---|
| 不同颜色 | 250 / 243 | 令牌化后 < 40（#322 第 6 步） |
| 不同字号 | 33 / 35 | 9（含半像素 7.5、9.5、10.5 等） |
| 不同圆角 | 25 / 22 | 7 |
| 不同阴影 | 69 / 64 | 3 |
| z-index 层 | 19 / 20 | 8 |
| 暗色模式 / `prefers-contrast` | 无 | #322 第 7 步，所有者定 |

规则：
1. **新代码只用 §2 的标尺和 §1 的令牌**；确实需要新值，先改这份文档的标尺，再写代码。
2. **碰到旧写死值就顺手换成标尺值**，同一个 PR 里把 `tests/spec/design_budget.json` 的预算往下调（测试会提示）。
3. 改全局颜色（令牌值）会影响所有页面，必须真机看过并在 PR 里写明手机端 / 网页端各看了没有。
4. 改了令牌值，同一个 PR 改这份文档的令牌表，否则测试变红。
