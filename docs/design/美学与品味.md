# 美学与品味（南伴球的整体审美，11-19 沉淀）

来源：首页引导条一整轮设计里所有者反复纠正的审美取向（太重、像原型 demo、分割严重、要轻盈高级、要有呼吸感和静感、要温馨安静），加上之前海报 / 空状态 / 前端风格已定的东西。**这里是总纲**：动效细节见 `动效与引导设计.md`，令牌数值见 `前端风格.md`，角色与场景见 `角色与场景.md`，海报口味见 `.claude/skills/nanbanqiu-poster/品味手册.md`，空状态见 `.claude/skills/nanbanqiu-empty-state-ux/SKILL.md`。

## 一、总纲：轻、静、暖、可信
- **轻**：用户第一眼的感觉是「轻松」，不是「被通知」。一切元素能小就小、能薄就薄、能淡就淡，不用厚色块、粗边框、重阴影。
- **静**：有留白、有停顿、有等待。画面不同时有两个以上的强调。安静不等于空，而是每个元素都有理由。
- **暖**：有一点人情味和会心一笑（小毛、一盏等你的灯、一颗蹦进来的球），但不卖萌、不过度拟人、不写口号。
- **可信**：对齐、比例、对比度、真实数据都经得起细看；没有数据就不显示数字，不押注库存。

## 二、对标与取舍
| 来源 | 我们拿什么 | 我们不拿什么 |
|---|---|---|
| Apple | 克制、物理感的运动、系统字体、留白、「用完即走」的提示 | 冷峻的纯黑白科技感（南伴球要暖） |
| Google / Material | 动效的编排（谁先谁后有因果）、强调缓动、状态可预期 | 大面积彩色块、层层阴影 |
| 奢侈品牌 | 短句、字距、少即是多、不描述功能、情绪先行 | 距离感、冷淡、过度矜持 |
| 皮克斯 / 小台灯 | 用「动作」而不是「台词」表达情绪；物件有注意力 | 复杂角色、表情包式夸张 |
一句话：**Apple 的克制 + Google 的编排 + 奢侈品的文案 + 皮克斯的温度。**

## 三、视觉原则
1. **层级只有一个主角**：每个画面只有一个最亮、最大、最先被看到的东西（引导条里是球）；其余让位。
2. **不做硬分割**：图与底之间用渐隐、同色过渡衔接，不用一条生硬的竖线或色块边界（最早那版的「分割严重」就是这样来的）。
3. **颜色克制**：底色 = 主题深绿或浅暖白；强调色只有青柠一个；中性色带一点绿相，不用纯灰。一屏里强调色只出现在最重要的 1–2 处。
4. **对比度与可读性优先**：小字也要达标（见 `前端风格.md`）；暗底上的小字不靠不透明度偷懒。
5. **比例协调胜过尺寸大**：元素的大小要和场景里的参照物一起看（球径 ≈ 球场宽的 1/11 才协调）；放大不等于更重要。
6. **圆角、阴影、描边按角色用**：只给需要被看作「一个物件」的东西；不要给每块都加。
7. **图是真的才画**：场景、场地线、灯杆的位置有现实依据；装饰性元素要有理由。

## 四、文字与文案
- **字体**：系统无衬线；靠字重对比（细 + 粗）、字距（标题 .04em、小标题 .16em）和字号建立层级，不靠花哨字体。真实站不能依赖网页字体。
- **文案公式**：先写用户此刻的心理，再写一句邀请。短（≤ 10 字一行）、不描述功能、不依赖球局数量 / 人数 / 时间（冷启动期会落空）。例：「挑一场，加入。」「不用认识谁，来就好」。
- **语气**：像朋友说话，温和、不催促、不卖弄；中文用全角标点，句末的句号让语气更笃定。
- **数字**：没有真实数据就不显示；有数据也要在数量少时隐藏，不显得冷清。

## 五、动效与节奏（摘要，细节见动效文档）
一个高光；有静、有等待、有呼吸；主角始终最亮；运动有物理依据；亮暗变化只增不回头；任何操作立刻让路；开了「减少动态效果」直接静态。

## 六、用户心理与出现频率
- 想打球却没搭子的人在意的是：**有人、有地方、不尴尬、不被打扰**。
- 一个好的引导让人觉得「被欢迎」，不让人觉得「被教育」。
- 频率：值得每天看一次的东西才每天出现；每端每天最多一次；深链进来不打断；曝光足够后再考虑只给新用户。**不为曝光做埋点**（所有者 11-19 定：不必要，先靠会话数据看整体）。

## 七、反模式（出现就改）
厚重大色块 · 像原型 demo 的拼接感 · 图与底硬分割 · 同时出现三种强调（衬线粗体 + 编号圆圈 + 青柠大字）· 主角被调暗 · 灯 / 光「亮—暗—亮」的闪烁 · 球或图标相对场景过大 · 文案押注库存 · 过度拟人和口号 · 把功能说明当文案 · 开场没有静拍就直接放大招。

## 八、评审清单（出图 / 出原型前自查）
1. 这个画面的主角是谁？是不是最亮最先被看到？
2. 有没有硬分割、厚色块、重阴影？
3. 强调色是否只有一个、只在最重要处？
4. 文案是否情绪先行、不描述功能、不押注数据？
5. 比例是否协调（和参照物一起看）？
6. 有没有静、有没有等待？动效有没有「回头」的变化？
7. 手机和电脑都看了吗？暗色 / 减少动态 / 系统字体呢？
8. 用户第二次、第十次看到，还愉快吗？
