# 角色与场景档案

每个角色 / 场景范式一条：**现行标准**（以代码和成品图为准）+ **已否决的做法及原因**（防止走回头路）。新角色、新场景在同一个 PR 里补进来；点评和拍板记到 `决定记录.md`。
做海报先读 `.claude/skills/nanbanqiu-poster/SKILL.md` 和同目录 `品味手册.md`；做空状态先读 `.claude/skills/nanbanqiu-empty-state-ux/SKILL.md`。

## 小毛（男，网球，品牌荧光黄绿）
- **现行标准（10-30，所有者点名「这个小毛设计得很好」= 78 号画法）**：立体柔和的球（36 号同款：渐变 + 极细颗粒 + 干净奶白球缝，光和场景同源）+ 微笑脸（深色竖椭圆眼 + 小白点高光 + 小弧线嘴 + 腮红）+ **黑色手写细线手脚** + 白色小球鞋。**不画眉毛、睫毛、头顶的毛。**
- **代码入口**：`marketing/mao3.py` 的 `figure3(id, cx, cy, r, pose, mood, gy=…, char='mao')`（脸用 `marketing/mao2.py` 的 `face2`）。成品：`marketing/posters/p78_mao_pen.py`（设定图）、`marketing/posters/p84_mao_rong_sunset.py`（场景）。
- **App 里的画法**：`marketing/icons/helpers.py`，手脚改成**流畅单笔线**（覆盖 `mao3.pen`，去掉 `rough2` 抖动）；viewBox 220×220、球半径 42、地面 y=198；一个动作 + 一个道具。海报里可以保留手写感。
- **黑线只放浅色底**；深色 / 场景底上手脚线改奶白色。

- **现行标准**：嫩粉立体球（`mao3.py` 的 `PINK`，中间色棉花糖粉 `#FFC6D8`）+ **一个白色小蝴蝶结**，其余和小毛一致（同样不画睫毛）。`figure3(..., char='rong')`；成品 `marketing/posters/p80_mao_rong.py`（合照）、`marketing/posters/p81_rong_pen.py`（设定图）、84 号（场景）。

## 场景范式：36 号「早安小球」（所有者 10-29：「无论是背景还是人物，非常好」）
代码 `marketing/posters/p36_good_morning.py`。先选一个有画面感的时刻（日出、傍晚球场、雨后、夜里泛光灯）搭场景，再放角色；**不要先画角色再找背景**。
1. 角色是场景里的一员，只负责一个动作 + 一个表情；背景讲故事。
2. 背景 = 渐变天空（3–4 色竖向）+ 放射光芒（淡奶白三角，透明度约 .16）+ 一团暖光 + 几层平涂山丘（层次靠深浅，不靠细节）。
3. 球是整张最亮的点，背景用青绿 / 暖色衬；一张只讲一个想法。
4. 出图先看大图，再看 360 宽缩略图；每轮只改一个变量。
