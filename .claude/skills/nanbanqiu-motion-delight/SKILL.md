# 动效与引导设计（做法）

知识（理念 / 设计语言 / 节奏表 / 技巧 / 踩坑 / 进化记录）都在 `docs/design/动效与引导设计.md`，**先读它**，整体审美总纲在 `docs/design/美学与品味.md`；最终可播放原型：`docs/design/原型_球场灯引导条.html`；正式实现：`src/shared/script/0502-首页引导条.js`、`src/shared/style/0330-首页引导条.css`、规则 `0501`。本技能只写步骤。

## 步骤
1. **一句话写下用户此刻的心理**（如「想打球又怕没人」），文案只写情绪与邀请，不押注球局数量、时间、人数。
2. **想一个只讲一件事的小故事**，每一步是上一步的结果；只留一处高光，其余安静。先参考的对象：Apple / Google 的物理感与克制、奢侈品牌的短句与留白。
3. **出静态效果图**（Playwright 截图一张对照现状）给所有者看方向；再做**可播放原型**（发布成 Artifact，顶部放：电脑 / 手机、节奏、重播、文案候选）。一次只改所有者点名的那一处。
4. **自查**：逐帧定格再截图，不靠计时截图——`document.getAnimations().forEach(a=>{a.pause();a.currentTime=t})`。看三件事：主角是否始终最亮；有没有回头的变化（亮—暗—亮）；比例是否协调。
5. **所有者拍板后**才进正式代码：只改 `src/`，`node tools/build.mjs` + `node tools/lint.mjs`；时间线统一乘系数 K（`window.__NBQ_INTRO_K` 供测试缩短）；写进 `tests/frontend/`。
6. **每次所有者点评**：在 `docs/design/决定记录.md` 追加一行；新的经验补进 `动效与引导设计.md` 的「踩过的坑」和「进化记录」。

## 换主题复用（套路）
夜（暗底）→ 主角入场（有物理的运动）→ 光源发现主角并亮起 → 光铺开回到主题色 → 一句话 → 停留 → 自然收起。可换：节日（换夜色与灯色：春节红金、圣诞绿红）、成功页（主角= 完成的对象）、空状态（主角= 小毛，光源= 台灯）。编排、缓动、分层、遮罩半径动画、检查清单都不变。

## 红线（来自 11-19 的教训）
- 灯亮、光铺开必须**单调上升**，任何「微暗」都会被看成电流闪。
- 主角放在遮罩之上的独立图层，别让它跟着变暗。
- 总时长长就必须「任何操作立刻让路」，并限制频率（每天每端一次，规则见 `0501`）。
- 真实站只能用系统字体；开了「减少动态效果」直接显示最终画面；页面不可见时先不开始。
- 改展示规则 = 同时改 `tests/unit/intro_rules.mjs` 和 `tests/frontend/intro.js`。
