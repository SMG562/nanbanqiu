来源：2026-10-29 同一用户连续 72 张海报的真实反馈。目标：下一张比上一张更好，不再踩他点名不喜欢的坑。

## 一、他的口味
**明确喜欢**（按他的原话归纳）
- 品牌深绿 + 荧光黄绿球、克制、有氛围的画面。

## 二、创意怎么选（从高到低）
1. 形似双关（A 看起来像 B，且都成立）。
2. **网球冷知识 / 规则 / 器材数字 × 约球的人的小心思**，用网球物件承载（球罐、钟面球、球网剖面）。
3. 一个被观察到的真实小细节（袜子红、球印压线、吊牌「至今没断」）。
4. 自然 / 城市里的壮阔场景，球场只是其中一点光。
最低：用文字讲道理、拆字、喊口号、借别的 App 界面、堆元素。**删掉文案画面也要成立。**
- 冷知识只用**真的**：球网立柱 1.07 m、中间 0.914 m；计分 15·30·40，来源是"相传钟面"，要写"相传"。拿不准的数字不写。

## 三、文案规则
- 一张最多一两句，≤ 12 字一行，陈述句，句号收尾；字小、克制，画面是主角。
- 像朋友随口一句：「今天风有点大。」「看情况。」「我才没在等。」「中间矮 15 厘米，球还是挂了。」
- 禁：「A，才B」「一个人…两个人…」「只要…就…」、升华、劝导、感叹号、口号。
- 小标签用地点 / 时间 / 英文名词（`MELBOURNE · 8:40 PM`、`NET HEIGHT`），不讲道理。
- 不写没确认的功能、真实球场名；产品事实以 `业务规则.md` 为准。示意数字要 `demo=True`。
- **歌词 / 流行文化**：不引用、不改写歌词（连改几个字也不行）；不借真实歌名、App 外观。只借**情绪**（无奈、可怜兮兮、等待）和**结构**，文案全部原创。

## 四、画面规则
- 一张只讲一件事；主体明确，留白有目的。
- 主调深绿 + 荧光黄绿球；可借季节色 / 大色块（橙、蓝、米），球仍是最亮的点。
- 光有来源；天空保持深，不要被光晕染成灰雾。
- 有层次；纹理（颗粒、草丝、泥纹）细而克制；同一张保持同一画风。
- 球和月面保持干净，不要随机斑点。
- **字标 `wordmark` 的圆点是荧光黄绿**：放在黄绿 / 浅色大色块上会看不见 → 底部做一条深绿 / 深色条再放字标（50、58、67 都踩过）。
- 标题实际用 56–66 号、y=290 起两行；小标签 y=150；字标 y=1268。

## 五、出图自检（每张看完图逐条过）
1. 一句话说得清创意吗？删掉文字还成立吗？
2. 文案有口号 / 哲理 / 「A，才B」吗？有 → 改成大实话或删掉。
3. 梗是装在**网球自己的东西**里吗？还是借了别的界面？（借界面 → 重做）
4. 有"看一会儿才笑"的小细节吗？（标注、划掉、小字、吊牌、时间）
5. 有脏点、硬边色带、糊雾、黑色大空块吗？下半部分是不是空了一大片？
6. 文字压住主体 / 互相压 / 离边 < 24px 吗？雨滴、虚线、抛球轨迹压到标题吗？
7. 字标在吗，圆点看得见吗？
8. 缩成 360 宽缩略图还能认出主体吗？
9. 事实对吗？数字、术语查证过吗？
10. 和已有海报撞题吗？先 `build.py --list`。

## 六、常见缺陷与修法
- 标签 / 物体压到文字 → 先算物体上下沿再定位（21、60 抛球、53 车灯像眼睛 → 加车身剪影）。
- 云带像硬色带 → 去掉裁切，用 `bl28`/`bl14` 的柔云。
- 圈错对象 → 先算目标中心坐标。
- 倒影压字标 → 压扁倒影或移开。
- 拆字直线切不开 → 渲染单字 + 参考线，折线 clipPath，补集 evenodd（只在不得不做时）。
- 影子认不出 → 少拉伸，加粗线条，减小 scale（47）。
- 树冠像紫雾 → 成簇小圆，不要大模糊圆（44）。
- 前景大块纯黑 → 加路、车灯、树线（41）。
- 标注文字压到曲线 → 把标注挪到参照线外侧（71 的「15 cm」）。
- 刻度压住数字 → 数字位置不画刻度（70）。
- 浮空物体 → 阴影椭圆贴地、物体底边落在地平线（60 手机）。
- 光晕把天空染灰 → 缩小光晕半径，用冷白。

## 七、迭代方式
- 每轮出 3–4 张**不同方向**，一次看完；他选定后只改被点名细节，别重新设计。
- 他说"不太喜欢"就把原因记进本手册，不辩解；说"好"也记进去（原话评语最有用）。
- 他喜欢的方向才继续成系列；没反馈的不要自作主张加码。
- 汇报：每张一句画面 + 一句文案 + 最想推荐哪张；不复述步骤；改过什么只说一句。

## 九、角色「小毛」（10-29 起）
- 要**更灵动、可爱的网球小人**，参照 33–36：亮眼睛 + 腮红 + 小笑。**不要**半睁眼、八字眉、波浪嘴、一条线嘴（73–75：「看起来不舒服、奇怪」）。
- 球长手长脚（粗的、黄绿色，76–77）也奇怪；他要的是**黑色手写细线画手脚**，和写实球形成「实 / 简」对比，简约大气，「一定要好看」（78–79）。
- 黑线必须放浅色底；没反馈前不要加表情、周边。
- 10-29「非常好」：78–79 的黑线手脚画风被认可。同日要求**男、女两个角色，是好朋友**：小毛（男，头顶一小撮毛）、小绒（女，高马尾、蝴蝶结、睫毛、白网球裙），80 合照 / 81 小绒设定图；78、79 的小毛随之加了那一小撮毛。
- 10-29：女生角色**用一颗粉色的球**表示（比马尾 / 裙子好，更简约）；强调**细节决定高度**：动作和表情要认真做（眉毛、睫毛、鞋带、歪头、闪光星、睡着的鼻泡、击掌成 Λ 形不缠成一根）。

- 10-29 小绒 v3 反馈：睫毛奇怪、比例奇怪、球面太光滑像蛋、粉色不够嫩 → v4：去睫毛，球要毛茸茸（毛须 + 纤维），粉用棉花糖粉，眼睛大而圆、手脚短。
- 10-29 v4 首版毛须边缘被说不自然、小毛头顶三根毛画蛇添足 → 改毡面质感（边缘软、不画毛须），小毛头上不加东西。
- 10-29 毡面颗粒太粗「疙疙瘩瘩没美感」→ 颗粒要细、起伏小（surfaceScale≈.75，频率高并轻微模糊），像天鹅绒。
- 10-29 毡面颗粒再被说「疙疙瘩瘩」→ 球面走动漫赛璐璐风：光滑渐变 + 柔和暗部 + 左上高光 + 左下反光，不加噪点颗粒；绒感只靠球缝上的几根细绒和很淡的边缘光晕。
- 10-29 高光 / 渐变「像苹果」→ 要平面设计风：纯色球身，无高光无渐变无暗部；绒感只靠轮廓同色细毛边 + 极淡短绒纹 + 球缝几根细绒。人没有高光，球也不要有。
