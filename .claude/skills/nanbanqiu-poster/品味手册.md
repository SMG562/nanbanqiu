# 南伴球设计品味手册（做任何新海报前先读，约 2k token）

来源：2026-10-29 同一用户连续 48 张海报的真实反馈。目标：下一张比上一张更好，不再踩他点名不喜欢的坑。

## 一、他的口味
**明确喜欢**
- 品牌深绿 + 荧光黄绿球、克制、有氛围的画面（最初 16 张："比我想的还要好"）。
- **形似双关**：一个东西同时是两件事，且一眼成立。例：月亮上两道浅弧线 = 球缝（25 号"即像网球，又像月亮"，后来点名"我喜欢上一版那个"）。
- 写实光影、深空、真实质感（26–28 月亮"都不错"）。
- 自然、大气、美观的题材：日月星辰、草木花树、山川湖海、城市万家灯火。
- 会心一笑的**大实话**：打过球的人才懂的小毛病（风大、袜子红、鞋里有沙、膝盖有意见、灯比我先亮）。
- 小球的拟人只在**有故事**时可以（晚安、早安成对），他夸"可爱"，但紧接着说"不是为了可爱而可爱"。

**明确不喜欢（点名）**
- 37「一个人，是半。两个人，才是伴。」、38「球，就是求一个人。」、40「隔着一张网，才有来有回。」——**煽情、刻意、喊口号、讲道理**；拆字、哲理金句、「A，才B」句式。
- 月亮表面"脏"：椭圆斑点像污渍；月亮位置太低；缺深空月光的意境。
- 为萌而萌。

## 二、创意怎么选（从高到低）
1. 形似双关（A 看起来像 B，且都成立）。
2. 一个被观察到的真实小细节（红土袜子红、风吹倒沙丘草）。
3. 大自然 / 城市里的壮阔场景，球场只是其中一点光。
4. 术语或冷知识的轻双关（love all = 零比零），只用真的。
最低：用文字讲道理、拆字、喊口号、堆元素。**删掉文案画面也要成立。**

## 三、文案规则
- 一张最多一句，≤ 12 字，陈述句，句号收尾；**字小、克制，画面是主角**。
- 要像朋友随口一句：「今天风有点大。」「球场的灯，比我先亮。」「今晚，有人在打球。」
- 禁：「A，才B」「一个人…两个人…」「只要…就…」、升华、劝导、问句、感叹号、「我们」式口号。
- 加一条小标签（地点 / 时间，如 `MELBOURNE · 8:40 PM`）比讲道理更有共鸣。
- 不写没确认的数字、功能、真实球场名；产品事实以 `业务规则.md` 为准。

## 四、画面规则
- 一张只讲一件事；主体明确，留白有目的。
- 品牌主调深绿 + 荧光黄绿球；季节色可借用（蓝花楹紫、日落橙）但球仍是最亮的点。
- 光要有来源：月亮冷白光晕、泛光灯、日落；天空保持深，不要被光晕染成灰雾。
- 有层次：远景薄雾、中景主体、前景暗色框景；纹理（颗粒、草丝、泥纹）要细而克制。
- 同一张保持同一画风：写实就写实，扁平就扁平。
- 球上和月面保持**干净**，不要随机斑点；需要质感用毛毡颗粒滤镜。

## 五、出图自检（每张看完图逐条过）
1. 一句话说得清创意吗？删掉文字还成立吗？
2. 文案有口号味、哲理味、「A，才B」吗？有 → 改成大实话或删掉。
3. 有脏点、硬边色带、糊雾、黑色大空块吗？
4. 文字压住主体 / 互相压 / 离边 < 24px 吗？标签在深浅背景上看得清吗？
5. 品牌标 `南伴球` 在吗？是否被倒影、物体盖住？
6. 缩成 360 宽缩略图还能认出主体吗？
7. 渐变中间是否发灰发脏？（teal→橙要加粉桃中间色）
8. 和已有 48 张撞题吗？（先 `build.py --list`）

## 六、常见缺陷与修法
- 标签压到物体 → 先算物体上下沿再定文字位置（21 号）。
- 云带像硬色带 → 去掉裁切，用 `bl28`/`bl14` 的柔云（25 号）。
- 圈错对象 → 先算目标中心坐标（24 号红圈）。
- 倒影压品牌标 → 压扁倒影或移开（31 号）。
- 拆字海报直线切不开 → 渲染单字 + 参考线，折线 clipPath，补集用 evenodd（37、38）。
- 影子认不出是人 → 去掉过度拉伸，加粗线条，减小 scale（47 号）。
- 树冠像紫雾 → 用成簇小圆（分层锐利 + 轻微模糊），不要几个大模糊圆（44 号）。
- 前景大块纯黑 → 加路、车灯、树线等小细节（41 号）。
- 光晕把天空染灰 → 缩小光晕半径，用冷白（26 号月亮）。

## 七、迭代方式
- 每轮出 3–4 张**不同方向**，一次看完；他选定后只改被点名的细节，**别重新设计**（"只是把表面脏点去掉，位置再调高"）。
- 他说"不太喜欢"就在手册里记下原因，不要辩解。
- 他喜欢的方向才继续做成系列；没反馈的不要自作主张加码。
- 汇报：每张一句画面 + 一句文案 + 最想推荐哪张；不复述步骤。

## 八、没做过的方向
同一场地四个时间（清晨 / 正午 / 傍晚 / 深夜）的光影组图；雨后球场；秋叶球场；凌晨海港；雪夜；星空露营旁的球场；灯塔；海边日出；城市屋顶球场；更多"形似双关"（球 = 月 / 日 / 蒲公英 / 柚子，但保持干净）。
