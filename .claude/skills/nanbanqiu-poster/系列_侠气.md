## 一、一句话公式

**侠气 = 球品。** 一个江湖母题（成语、诗句、武侠画面）× 一条球场上的好品行或真规则 × 一句带点笑的大白话。

- 不画打打杀杀。侠气是**收拾干净、点到为止、说到做到、帮人一把**。
- 「哈哈」是这个系列的核心：江湖腔说的是球场里最日常的小事，反差就是笑点。
  - 「事了拂衣去」→ 球都捡干净了。
  - 秘籍口诀 → 抛歪了可以再抛。
- 每张仍然藏一个南伴球的真实卖点或规矩：
  - 守约、不爽约（220）
  - 同水平切磋（219）
  - 新手友好、真规则（221）
  - 打完收拾场地（218）

## 二、画风

### 侠客小人（`xia.hero()`）

- 斗笠（`hat='douli'`）或束发（`hat=None`）。
- 披风往后飘，用一抹朱红 `#C23A2B`，或石青 `#1E4E62`。
- 球拍斜背在身后，像背剑（`back=True`）；出招时 `arm='up'` 举拍。
- 永远是远景小人，不画五官，剪影要一眼认得出：斗笠、披风、拍。

### 字和颜色

- **毛笔感大字**（`xia.brush_v()`）：粗宋 900，加上轻微抖动滤镜 `#brush`，每个字微旋 ±3°。浅底用墨色 `#1E1A14`，深底用月白 `#F4EDCF`。
- **场景**（每张一个，都要有大面积南伴绿）：
  - 落日草原：风吹草用斜向细笔。
  - 竹林：竖竿分远中近三层，左上留雾白放字。
  - 雨夜：一盏球场灯的光锥里雨丝发亮，地上有倒影。
  - 布面秘籍：南伴绿斜纹布、线装书页、朱丝栏。
- **动势**：`xia.qi()` 剑气光带（两头收的亮带）用来画球的轨迹。可以加一个小细节，比如被剑气划断的竹叶。
- **颜色**：南伴绿占大头；朱红只给披风、印、口诀标题；荧光黄绿只给球。

### 版式（同诗人打球）

- **左边**：竖排大字。
- **大字右侧**：小竖排，放一句江湖话或出处。
- **朱印**「南伴」。
- **左下** `footer()`：
  1. 大白话
  2. 「侠气 · 编号 / 题」
  3. 英文意译
- **右下**：落款。
- 秘籍类例外：书页铺满上半，书名横排在右上，口诀竖排在右，招式图放左下框里。

## 四、踩过的坑（自检）

- [ ] **红线**：不做阴暗、恐怖（见总纲第 0 条）。220 那种雨夜以后也要画亮：灯光暖、场地亮、人物有颜色，不画黑剪影。

- [ ] 侠客手里要有拍。`scholar` 默认 `arm='down'` 会画拍子，要空手用 `arm='none'`。背拍和手拿拍别同时出现。
- [ ] 前景的竹竿、杆子别挡住人物（219 第一版左边那个人被竹竿遮了）。
- [ ] 夜景别撒没有意义的小光点（220 第一版的「城市灯」像噪点，删了）。
- [ ] 秘籍书页里：图注、标注线别压到框线和边框（221 返工过）。
- [ ] 两列竖排时，先读的在右。
- [ ] 不借武侠小说的人名、门派、招式名、台词（「侠之大者」「华山论剑」「降龙十八掌」都不用）。不用暴力诗句（「十步杀一人」不用）。不出现真实寺庙、门派。
- [ ] 口诀里的规则必须真实。拿不准就不写。

秘籍体的规矩：
- 书名「南伴球谱」，卷次和式名用朱红。
- 招式图用远景小人加虚线、箭头和标注，标注 2–3 处。
- 口诀 4–6 列，每列 ≤ 10 字。
- 底部大白话把口诀翻译成人话。
