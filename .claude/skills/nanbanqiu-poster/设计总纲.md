# 南伴球视觉设计总纲（所有宣传物料的上位文档）

> 管：品牌海报、系列海报、每日球局推广图、App 里的分享图和空状态插画。
> 来源：所有者 2026-10-29 到 11-08 对 200 多张图的逐张反馈。原话和过程在 `品味手册.md`，各风格的结论在 `风格库.md`。
> 本文只写**已经被反复验证的结论**。新反馈先记进品味手册，**同一结论出现两次**才升到这里（见 §九）。

## 一、南伴球的视觉性格

**南伴绿打底，荧光球点睛；光亮、开阔、会心一笑。**

| 是 | 不是 |
|---|---|
| 光亮饱满：天地开阔，人很小，心里很宽 | 沉郁顿挫、灰暗、通篇浅灰浅粉 |
| 简约大气：靠比例、留白、字距 | 为设计而设计：花样字标、堆特效、堆元素 |
| 会心一笑：双关、冷知识、大实话、让网球入戏 | 喊口号、讲道理、煽情、「A，才B」 |
| 故事简单清楚动人：一眼看懂 | 像一帧电影画面、需要解释、不明所以 |
| 学大师的方法 | 照搬大师的题材、元素、外观 |
| 真实的球场生活 | 编造的功能、真实球场名、真人照片、别人的商标 |

## 二、十条原则（按优先级）

1. **南伴绿大面积出现**。不管借什么风格（宋画、日系、课本、综艺），深绿或绿都要占画面大块：地面、山、场地、树、荷叶、抬头。浅色只做留白和天。
2. **荧光黄绿只给球和最重要的一个点**，它是整张最亮的颜色。别处不用它当装饰色。
3. **光亮饱满**。可以画夜景，但要有一个大光源（月、灯、曙光）把画面撑亮。不做褪色蒙层，不做整张灰雾。
4. **一张只讲一件事**。元素宁少勿杂，有余力就把细节做足。删掉文字后画面也要成立。
5. **人小天地大**。人物是远景小人，不画五官，用场景和结构说话。人物画不好时就把镜头拉远。
6. **学思维，不学外观**。借大师、电影、品牌、综艺的方法（构图、光、版式、讲故事），题材必须是南伴球自己的。不借片名、台词、歌词、商标、台标、吉祥物、真人肖像。
7. **会心一笑**。按这个顺序选创意：
   1. 形似双关
   2. 网球冷知识或真实数字
   3. 打过球的人才懂的小细节
   4. 自然和城市的壮阔场景

   讲道理、拆字、喊口号永远是最后一名，别做。
8. **藏一个真实卖点**。把产品事实放进画面：按水平约、7 天窗口、找球友、南半球、早场、夜场、雨天改期。不编造功能。功能以 `业务规则.md` 为准。
9. **系列先定骨架**。先定颜色、网格、字号、落款和编号，再画画面。换内容不换骨架，这样才有系列感。
10. **简约大气胜过炫技**。字标、标题靠比例、字距、留白。笔画换图形、连笔、甩尾巴这类做法显得廉价，别做。

## 三、颜色

### 品牌核心（`lib.C`）

| token | 色值 | 用途 |
|---|---|---|
| deep | `#0B3B2A` | 最深的底、浅底上的字标 |
| green（南伴绿） | `#176B4D` | **主色**：抬头、地面、落款条 |
| mid | `#0E5139` | 阴影面、深一层 |
| 亮绿阶 | `#2F8A6E` `#3FA474` `#4DB27F` `#6CC597` `#8ED9B0` | 山、草、层次 |
| lime（荧光黄绿） | `#C6EA3D`；球面 `#DDF35A` | 球、唯一强调 |
| cream / paper | `#F7EBD6` / `#F3E6CC` / `#F3EFE4` | 纸底、留白 |
| ink | `#14231B` / `#2B3A3A` | 字。不用纯黑，用带绿的墨色 |

### 配比

大约 60% 底色（纸或天）、30% 南伴绿系、10% 强调色（荧光球加一个辅助暖色）。只有夜景能把底色换成深绿或石青。

### 系列辅助色（只在对应系列里用）

- **古色**（诗人打球）：石青 `#1E4E62`、石绿 `#2F8A6E`、月白 `#F4EDCF`、缃 `#F2DCA8`、朱砂 `#C23A2B`、黛 `#2B3A3A`。
- **课本怀旧**：泛黄纸、红标语 `#C8382B`、黑板绿（等于南伴绿）。
- **舞台风空状态**：鼠尾草绿单色调，加一点橙。
- **暖色点睛**：落日橙 `#F28A3A`、灯笼红 `#E8503A`。一张最多一个暖色主角。

## 四、字体与字号

- **标题**：思源宋体 `SERIF`，700/900。**信息**：思源黑体 `SANS`。英文小标签全大写，字距 5–9。
- **字号阶梯**（1080 宽画布）：

| 用途 | 字号 |
|---|---|
| 主视觉大字 | 96–112（竖排诗句、少字标题） |
| 标题 | 56–78 |
| 正文 / 一句话 | 30–38 |
| 说明 | 18–22 |
| 微小字（英文、编号、演职员表） | 12–15 |

- **标点**：中文用全角。短句用句号收尾，不用感叹号。
- **竖排**：逐字排，跳过标点。两列以上时**先读的在右**。
- **数字**：时间、比分用等宽数字（`tabular-nums`），粗体。

## 五、版式（1080×1350，4:5）

- **边距**：左右 64–84。任何字离画布边不少于 24px（`build.py` 会检查）。
- **三区**：
  - 上区：标题或抬头，约 y 80–300。
  - 中区：画面或信息主体。
  - 下区：落款带，y≈1190–1350，深绿地面或深色条，左边一句话，右边「南伴球」落款。
- **字标** `wordmark()` 或小落款里的圆点是荧光黄绿，放在浅色或黄绿底上会看不见，所以下面一定要铺深色。
- **画面主体**：要避开标题栏和落款带。透视线、雨丝、轨迹、白色物体都不要穿过文字。
- **其他尺寸**（小红书 3:4、故事 9:16）还没支持，见 SKILL.md「其他尺寸」。不要用裁 4:5 的办法凑。

## 六、画面

- **光**：只有一个光源，默认从左上来。球落地要加阴影椭圆。
- **层次**：靠颜色深浅（远浅近深），不靠细节堆。前景最深的一层托住落款。
- **人**：
  - 远景小人（`poet.scholar`、`people.person`、`wide.tiny`），不画五官。
  - 一张最多两个主角；人群只用抽象小人影。
  - 角色小毛、小绒按 `角色_小毛小绒.md` 画。
- **球**：用 lib 画的球。球面干净，没有随机斑点。网球可以扮演月亮、太阳、山、星球、黄鹂，但要一眼看出是球。
- **自然**：山、树、云、水做平涂或少量渐变。不用照片纹理，不加大块模糊雾。
- **质感**：颗粒、纸纹、笔触都要细而克制。缩略图里看不出来的不用调。

## 七、文案

- 一张一两句。一行最多 12 字（竖排诗句除外）。陈述句、句号收尾、口语，像朋友随口一句。
- **好句子**：「今天风有点大。」「独酌不如约球」「下雨也去，谁怕？」「两个人，就能开一局」
- **禁用**：
  - 「A，才B」「只要…就…」「一个人…两个人…」
  - 升华、劝导、感叹号
  - 歌词，以及改写歌词
  - 片名、台词
- **英文小字**做意译或地点时间（`MELBOURNE · 8:40 PM`），不翻成口号。
- **诗词**：原句照抄，最多改一个字，改字要改得妙。诗人和诗题都要核对。
- **数字**：只写真的。示意数据要 `META.demo=True`，页面会打「示意」角标。

## 八、出图自检（每张看完大图都过一遍）

1. 一句话说得清创意吗？删掉文字后还成立吗？
2. 南伴绿面积够吗？荧光球是最亮的点吗？整张够亮吗？
3. 元素能不能再删一个？只讲了一件事吗？
4. 文字有没有被压、互相压、离边太近？线条、雨丝、白色物体穿字了吗？
5. 落款在吗？圆点看得见吗？
6. 缩成 360 宽的缩略图，主体和标题还认得出吗？九宫格里还看得懂吗？
7. 事实、数字、出处查过吗？功能和 `业务规则.md` 一致吗？
8. 有没有借了别人的商标、台标、片名、歌词、真人？
9. 和已有的撞题吗？先跑 `build.py --list`，再看 `风格库.md`。
10. 这一张属于哪个系列？编号、骨架和系列一致吗？

## 九、怎么越做越好（迭代机制）

1. **每轮出 3–4 张不同方向**，一次给看，并说最推荐哪张、为什么。用户选定后只改被点名的细节，不重新设计。
2. **每轮反馈当轮记录**：
   - 原话和结论记进 `品味手册.md` §十「反馈日志」，一行一条，带日期和编号。
   - 结论（推荐、慎用、不要）同步到 `风格库.md` 那一行。
3. **升级规则**：同一个结论出现第二次，或者用户明确说「以后都要」，就升进本总纲。本总纲每条原则后面不写来历，来历在日志里。
4. **变成固定系列的条件**：用户说「非常棒 / 继续 / 做成系列」→ 单独开 `系列_<名>.md`，写清公式、骨架、坑、拓展清单（参照 `系列_诗人打球.md`）。
5. **样板库**：用户点名夸过的放进 `风格库.md`「样板」列。新做同类时先看样板，再动手。
6. **底稿全保留**：不删、不覆盖旧图，新版本用新编号。被否的标「不要」，留着当反面教材。
7. **复盘**：每做满约 20 张，把日志里重复出现的问题收成自检清单里的一条（§八）。
