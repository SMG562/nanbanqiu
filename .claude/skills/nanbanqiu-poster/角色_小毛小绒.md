# 角色：小毛 / 小绒（网球吉祥物）

> 画角色海报、App 空状态、表情包前读。定稿画法：`marketing/mao3.py` 的 `figure3()`（= 78 号，用户 10-30「这个小毛设计得很好」）。空状态图标另见 `marketing/icons/README.md`。

## 定稿画法与 API
- **角色「小毛」（10-30 定稿，用户点名「这个小毛设计得很好」= 78 号画法）：一律用 `mao3.figure3(id,cx,cy,r,pose,mood,gy=…,char='mao'|'rong')`**：36 号同款立体球 + 黑色手写细线手脚 + `face2` 的脸；**不画眉毛、睫毛、头顶的毛**；小绒 = 嫩粉立体球（`PINK`）+ 一个小蝴蝶结。场景海报（84）和设定图（78–81）都用它。**下面 v4（`mao4.py`，82–83）已弃用，仅留作记录**：v4，`marketing/mao4.py` 的 `figure4(id,cx,cy,r,pose,mood,char,gy=…)`：平面设计风纯色球（无高光、无渐变、无暗部；绒感 = 轮廓柔边（同色小半径模糊，**不是锯齿**）+ 极淡短绒纹 + 球缝几根细绒；不要外圈毛须、噪点颗粒、高光，用户都说不自然 / 疙瘩 / 像苹果；小毛头顶不要毛）、婴儿比例大眼睛（无睫毛）、嫩棉花糖粉 `PINK_P`、手脚更短；合照见 p82。**v3（78–81，`mao3.py`）球面太光滑像蛋、睫毛和比例被用户说奇怪，别再用**；以下姿势 / 笔触规则 v3、v4 通用。v3 说明：`figure3(id,cx,cy,r,pose,mood,char)`；两个角色：**小毛（男，`char='mao'`，头顶一小撮毛，嘴硬心软）/ 小绒（女，`char='rong'`，**一颗粉色的球**（`mao3.ball_c` + `PINK`）+ 奶油白小蝴蝶结 + 睫毛 + 玫瑰色腮红，话多守时；不要再画马尾、裙子）**，是好朋友；小绒用名字姿势时左右镜像（动作手在左，不和马尾打架）；合照用 dict 姿势 + `gy` 定地面线（见 p80）；：写实荧光球 + 33–36 同款脸（`mao2.face2`，眼睛用黑色）+ **只用黑色手写细线画手脚**（`pen` 双笔触 + `rough2` 抖动；手是小圆圈，脚是小椭圆球鞋，脚下一笔地面线）。**必须放浅色底**（奶油 `#FBF4E3→#F1E3C4`），黑线才看得见；浅色底字标圆点看不见，底部做深绿弧形条再放字标；标题用深绿 + `#C2410C`。pose=wave/cheer/plead/racket/wow/sorry/sleep；mood=smile/happy/cheer/wow/plead/wink/sweat/sleep；坐、抓绳等特殊姿势用 `pen/hand3/shoe3` 自己拼（见 p79）。v1（73–75 冷面脸）用户说「看起来不舒服、奇怪」，v2（76–77 黄绿粗手脚）用户说「球长手长脚奇怪」，**都别再用**。脸用 `face3`（face2 + 细眉毛 + 小绒睫毛 + 睡着的鼻泡）；细节：鞋带、求约的闪光星、歪头。口吻：陈述句、句号收尾、无感叹号。

## 角色 / 吉祥物设计方法（可复用，10-29 小毛小绒磨了 6 版才定）
1. **先问风格，再问材质**：用户要的是「正常的平面设计角色」，不是 3D 渲染。平面风 = 纯色块 + 干净线条；人没有高光，球也不要高光、渐变、暗部（加了像苹果 / 像蛋）。
2. **材质靠最少的暗示**：真实感做不好就别硬做，一个材质只留一个线索。网球绒感 = 轮廓一圈极轻的柔边 + 极淡的短绒纹（要凑近才看见）+ 球缝几根细绒。**绝不用**：外圈毛须（像刺）、噪点颗粒（疙瘩 / 砂纸）、锯齿三角毛边（锯齿感，网球不是这样）、高光反光。
3. **轮廓永远干净**：边缘要么光滑要么轻微柔化；任何「毛」都不能让剪影变成锯齿。
4. **婴儿比例**：大圆眼睛放低，嘴小成一个点，手脚短而细（黑色手绘线，小圆手、小鞋）；不要睫毛，性别靠颜色 + 一件小配饰（蝴蝶结）区分。
5. **配饰做减法**：男性角色头上不加毛 / 帽子；每个角色最多一件配饰。
6. **颜色**：粉要嫩（棉花糖粉 `#FFC6D8` 平涂），黄绿用品牌荧光黄绿；放在浅色底上让黑线、粉色都看得清。
7. **改版节奏**：每一轮只改一个变量，出图后先看大图再看缩略图；用户说「奇怪 / 不自然」时，先判断是**材质过度**还是**比例**问题，别在原方向上继续加细节，往简化方向退一步。

## 角色海报的「36 号范式」（用户 10-29 点评「无论是背景还是人物，非常好」，以后角色海报先照这个想）
36 号「早安小球」好在哪（对照 `posters/p36_good_morning.py`）：
1. **角色是场景里的一员，不是孤立的贴纸**：球像朝阳从草坡后升起，只露大半个。背景在讲故事（光芒、天空、远山），角色只负责一个动作 + 一个表情。别再把角色单独摆在空白奶油底上堆细节。
2. **背景是「渐变天空 + 几层平涂剪影」**：天空 3–4 色竖向渐变（青绿 → 灰绿 → 蜜桃 → 奶黄），放射光芒（淡奶白三角，opacity≈.16），一团大半径模糊的暖光，几朵模糊云，几只小鸟；前景 3 层深浅不同的绿色平涂山丘，最下一层最深，托住字标。层次靠颜色深浅，不靠细节。
3. **角色的脸极简**：两个深色竖椭圆眼睛 + 一个小白点高光 + 小弧线嘴 + 柔和腮红。没有睫毛、眉毛、反光、多余装饰。
4. **球的质感是「柔」的**：球身用柔和的渐变和极细的颗粒，球缝是干净的奶白带；光和场景同源（朝阳在后面），所以不显得突兀。被否的是**贴纸式的塑料高光 + 空背景**（像苹果），不是渐变本身。
5. **主色关系**：球是整张最亮的点（荧光黄绿），背景用青绿 / 暖色衬它；标题深绿 + `#C2410C`，底部深色条放字标。
6. **一张一个想法**：这一张只讲「早上也有球」。
**球身两种画法**：场景海报（36、84）用 `figure4(..., ball_style='soft')` = 36 号同款立体球（渐变 + 细颗粒 + 边缘暗角 + 干净球缝），角色有体积感；浅色空白底的设定图（82、83）才用默认 `'flat'` 平涂。用户 10-29 评 84 首版「平面的，没有 36 号立体」，场景里的角色必须立体。
**以后做角色（小毛 / 小绒）新海报**：先选一个有画面感的时刻（日出、傍晚球场、雨后、夜里的泛光灯），用上面的方法搭场景，角色按 36 号的脸画（可保留小毛小绒的黑色细线手脚，但脸和球身用 36 号的画法），再出图；不要先画角色再找背景。

## 反馈记录（10-29 – 10-30，按时间）
- 要**更灵动、可爱的网球小人**，参照 33–36：亮眼睛 + 腮红 + 小笑。**不要**半睁眼、八字眉、波浪嘴、一条线嘴（73–75：「看起来不舒服、奇怪」）。
- 球长手长脚（粗的、黄绿色，76–77）也奇怪；他要的是**黑色手写细线画手脚**，和写实球形成「实 / 简」对比，简约大气，「一定要好看」（78–79）。
- 黑线必须放浅色底；没反馈前不要加表情、周边。
- 10-29「非常好」：78–79 的黑线手脚画风被认可。同日要求**男、女两个角色，是好朋友**：小毛（男，头顶一小撮毛）、小绒（女，高马尾、蝴蝶结、睫毛、白网球裙），80 合照 / 81 小绒设定图；78、79 的小毛随之加了那一小撮毛。
- 10-29：女生角色**用一颗粉色的球**表示（比马尾 / 裙子好，更简约）；强调**细节决定高度**：动作和表情要认真做（眉毛、睫毛、鞋带、歪头、闪光星、睡着的鼻泡、击掌成 Λ 形不缠成一根）。

- 10-29 小绒 v3 反馈：睫毛奇怪、比例奇怪、球面太光滑像蛋、粉色不够嫩 → v4：去睫毛，球要毛茸茸（毛须 + 纤维），粉用棉花糖粉，眼睛大而圆、手脚短。
- 10-29 v4 首版毛须边缘被说不自然、小毛头顶三根毛画蛇添足 → 改毡面质感（边缘软、不画毛须），小毛头上不加东西。
- 10-29 毡面颗粒太粗「疙疙瘩瘩没美感」→ 颗粒要细、起伏小（surfaceScale≈.75，频率高并轻微模糊），像天鹅绒。
- 10-29 毡面颗粒再被说「疙疙瘩瘩」→ 球面走动漫赛璐璐风：光滑渐变 + 柔和暗部 + 左上高光 + 左下反光，不加噪点颗粒；绒感只靠球缝上的几根细绒和很淡的边缘光晕。
- 10-29 高光 / 渐变「像苹果」→ 要平面设计风：纯色球身，无高光无渐变无暗部；绒感只靠轮廓同色细毛边 + 极淡短绒纹 + 球缝几根细绒。人没有高光，球也不要有。
- 10-29 用户点评 36 号早安小球「无论背景还是人物都非常好」→ 角色放进有光的场景，背景分层、脸极简、球质感柔；详见 SKILL.md「36 号范式」。
- 10-29 84 号首版角色平涂被说「没有 36 号立体」→ 场景海报的角色球身用 ball_style='soft'（36 号画法）。
- 10-30 用户发 78 号图：「这个小毛设计得很好」→ 以 figure3（立体球 + 黑细线手脚 + face2 脸）为标准，去掉眉毛 / 睫毛 / 头顶毛；小绒只换成嫩粉球 + 小蝴蝶结。v4（mao4）弃用。
