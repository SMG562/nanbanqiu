## 一、一句话公式

**一句名诗 × 一个让网球「入戏」的画面 × 一句南伴球的大白话。**

- 诗负责「古意」，画面负责「耳目一新」，大白话负责「跟我有什么关系」。
- 网球不硬塞，而是**扮演诗里本来就有的东西**：月亮（207）、黄鹂（209）、南山（212）、星球（213）。扮不了的，就让人提着拍子出现在诗的场景里（208、210、211、214、216）。
- 每张都悄悄说一个**南伴球的真实卖点**，这是这个系列能打动人的原因：
  - 一个人也能约到人（207）
  - 打到天黑（208）
  - 两个人就能开一局（209）
  - 下雨也去（210）
  - 打累了歇着（211）
  - 品牌名谐音（212）
  - 南半球有球友（213）
  - 找搭子（214）
  - 按水平进阶（215）
  - 早场（216）

## 二、选诗：什么样的句子能用

1. **人人会背**：小学、初中课本里的那一句。冷门的再美也不用，看不懂就没有会心一笑。
2. **能落到一件球场上的小事**：时间（清晨、傍晚、夜场）、天气（雨、雪、风）、关系（知己、搭子、重逢）、成长（进阶、坚持）、地点（南半球、异乡）。
3. **字数**：主标题取 5–7 字一句。整首太长就只用一句，另一句做小竖排。
4. **改字只改一个，而且要改得妙**：「举杯 → 举拍」可以；大段改写、谐音乱改不行。不改字时，原句照抄。
5. **出处必须核对**：诗人、诗题都要写对，比如《青玉案·元夕》、《送杜少府之任蜀州》。拿不准的句子就不用，常见的误传句要防。

## 三、画风：古色 + 现代版式（每张都照这个做）

### 古色调色板（`poet.py` 常量，加上品牌绿）

| 名 | 色值 | 用途 |
|---|---|---|
| 石青 | `#1E4E62` / 夜空 `#143A4C` | 夜景、深色天 |
| 石绿 | `#2F8A6E` | 山、场地 |
| 南伴绿 | `#176B4D` 深 / `#3FA474` 亮 | **每张都要大面积出现**：地面、山、球场、荷叶、柳 |
| 月白 / 缃 | `#F4EDCF` / `#F2DCA8` | 月亮、暖底、晨昏 |
| 朱砂 | `#C23A2B` | 印、腰带、点睛的一两个字（「谁怕」） |
| 黛 | `#2B3A3A` | 浅底上的主标题 |
| 网球黄绿 | `#DDF35A` / `#C6EA3D` | 只给球和品牌点 |

- 底色要亮。可以用夜景，但要有一个大光源（月亮、灯笼、曙光）把画面撑亮。整张灰暗的不行。
- 全部平涂加少量渐变，不画笔触，也不做颗粒做旧。

### 版式骨架（10 张都一样，换诗不换骨架 = 系列感）

- **左上**：主标题竖排。`vtext(句, 150, 180–190, 96–112, 色, 1.12, 700)`，宋体粗。
- **主标题右侧**：另一句诗竖排小字。`x=256`，30px，行距 1.5。**两列小字时，先读的在右**（`x=300` 是第一句、`x=256` 是第二句）。208 和 214 都在这上面返过工。
- **朱印**「南伴」：放在小竖排下面，`seal(236, 450–520, 40)`。
- **左下**：`footer()` 一次画完三行加落款：
  1. 现代大白话，38px 宋体。
  2. 「诗人打球 · 编号 / 诗人《诗题》」。
  3. 小号英文意译，12px，大字距。

  右下角放「南伴球」小落款。footer 底下统一铺一条深绿地面或深色条（`y≈1190` 起），字压在上面。
- **画面主体放右侧和中下**，大块几何形状加大面积留白。字那一栏不要被画面压到。
- 编号用大写数字：壹贰叁…拾，接下来是拾壹、拾贰……

### 人物（`scholar()` / `sit()`）

- **永远是远景小人**：高约 100–160px，不画五官，宽袍随风往后飘，腰带一抹朱红或石青。人小才有天地，也能藏住画人的短板。
- 姿势：
  - 举拍：`arm='up'`
  - 提拍：`arm='down'`
  - 坐着：`sit()`，拍子用 `racket_lean()` 靠在旁边
  - 女子：`woman=True`，加发髻和簪子
  - 斗笠蓑衣：`hat='douli'`
- 一张最多两个人。人群只用 214 那种抽象的小人影。

### 「现代」从哪里来（每张至少用两条）

1. **几何化**：
   - 正圆月亮出血（207）
   - 正圆月洞门框景（216）
   - 大半球南山和星球（212、213）
   - 一层层轴测台阶（215）
   - 半圆云纹排成云海（211）
2. **换视角**：从正上方俯视荷塘（208），把荷叶变成满版圆点；湿地面上的倒影（210）。
3. **重复成图案**：柳丝做满屏竖线（209），灯笼做点阵、人海做颗粒（214）。
4. **信息层**：细线、小英文、编号、星座名「CRUX」、水平刻度「2.0–4.0」。像杂志版式，但要克制。

## 五、做的时候踩过的坑（自检清单）

- [ ] **竖排顺序**：两列小字时，先读的在右。
- [ ] **主标题背景要单一**：浅底配黛字，深底配月白字。主标题跨过明暗交界就会看不清，所以画面的地平线要放在主标题最后一个字下面。
- [ ] **白色元素别叠在一起**：白鹭别压着球（209 返过工），云别糊成一整块白（211 第一版：云海要有深浅两色交替，加下沿阴影）。
- [ ] **叠放顺序**：台阶要从最高一层往低处画（215 第一版低层盖住了高层）。
- [ ] **线别穿字**：球场透视线、中线别穿过左下大白话和右下落款。中线画到发球线就停（210）。
- [ ] **别出画外**：建筑、人物算好坐标再画。215 第一版小楼出了画面。
- [ ] **南伴绿面积**：每张缩到手机大小时，一眼要看得到大块的绿。不够就加草丛或地面（216 加了一排灌木）。
- [ ] **构图**：只有一个主体和一个故事，元素宁少勿杂。
- [ ] **两张小图同时看**：缩到朋友圈九宫格那么大，标题还认得出、故事还看得懂。
- [ ] 不用任何真实人物肖像、他人商标、赛事标识；诗人只画成背影或远景小人。
