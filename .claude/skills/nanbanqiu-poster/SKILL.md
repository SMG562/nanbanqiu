# 南伴球宣传物料（海报）

**第 0 步：先读同目录的 `品味手册.md`**（用户口味、点名不喜欢的类型、自检清单）。已有 184 张里 37 / 38 / 40（口号 / 拆字 / 哲理）和 66 / 67（借别的 App 界面）是反面教材；68–72（网球冷知识 × 小心思）是用户最近点名的好样板。

**先别读旧海报和 lib.py，按下面流程走，一张新海报约 60 行代码、几轮就能定稿。**
成品都在预览站「宣传物料」页（/materials.html，手机能看、能存大图），推送到 main 自动更新。

## 流程
1. `python3 marketing/build.py --list`：看已有海报的编号 · 标题 · 风格 · 创意，**不重复**；**编号先查别的分支**（`git ls-remote` + 各分支 `marketing/posters/`，多个对话会同时出图，11-08 撞过 85–88）；想不到方向就看文末「还没做的方向」。
2. 新建 `marketing/posters/pNN_slug.py`（NN 接着最大编号，slug 用连字符，文件名里换成下划线），照下面的模板写 `META` 和 `svg()`。
2b. **出图前确认装了思源字体**：`fc-list :lang=zh | grep -c Noto`，为 0 就 `apt-get install -y fonts-noto-cjk fonts-noto-cjk-extra`（11-08 云端容器没装，110–159 首版全用了文泉驿替代字体，已重出）；python 的 playwright 版本要和 /opt/pw-browsers 里的浏览器对上（`pip install playwright==1.63.0`）。
3. `python3 marketing/build.py --only NN`：出 `img/NN-slug.webp`（1080×1350）、`thumb/`（360×450），登记 `posters.json`，并**自动检查文字**（出画布 / 离边太近 / 互相压住；旋转组里的文字可能误报）。
4. 看图：Read `marketing/img/NN-slug.webp`（一张约 2k token）。多张对比用 `--sheet /tmp/s.jpg`（缩略总览，一次读完）。改数字或文案后重跑 `--only NN`，不要整文件重写。
5. 收尾：`node tests/frontend/site.js`（站点测试，约 15 秒，会核对 posters.json、源文件、图片是否对得上）→ 提交（`marketing/` 整个目录：源文件、posters.json、img、thumb）→ 推送。
6. 给用户高清大图：`python3 marketing/build.py --only NN --hires <用户电脑文件夹>/宣传物料`（PNG 1620×2025，不进仓库，.gitignore 已忽略 png）。电脑文件夹要先用 device_request_folder_access 接上。
7. 进度记录不用为每张海报单独写；posters.json 就是清单。只有品牌规则或流程变了才改本文件。

## 品牌规则
- **南伴绿必须看得见**（11-08 用户点名）：不管借什么风格（日系、优衣库、宋画），南伴深绿 / 绿要占画面大面积，不能通篇浅灰浅粉；浅色只做留白和天。
- **颜色**（lib.C）：深绿 deep `#0B3B2A`、green `#176B4D`、mid `#0E5139`；荧光黄绿 lime `#C6EA3D`（球和强调色）；奶油 cream `#F7EBD6`、paper `#F3E6CC`；复古系列才用 orange `#E8643C` / amber `#F2B134`；咖啡色 `#B0582F`。**主调永远是深绿 + 荧光黄绿，球是主角。**
- **字体**：标题衬线 `SERIF`（Noto Serif CJK，粗体 700/900），其余无衬线 `SANS`；英文小标签字距 9、全大写。
- **版式**（1080×1350）：左右边距 80 / 84；左上小标签 `tag()` 在 y=150；标题实际常用 56–66 号字、第一行基线 y≈290、行距 76–84（早期 112 号大字用于少字海报）；底部品牌标 `wordmark()` 在 y≈1268（深色底用 `#fff`，浅色底用 `#0B3B2A`）；最后加 `grain()`（浅色底 `light=True`）。留白要足，一张只讲一件事。
- **文案**：短句，口语，温暖，句号收尾，全角标点；标题两行，第二行用强调色；112 号字一行最多 7 字（96 号 8 字）。常见结构：「前半句，后半句。」不夸张，不写没确认的数字、功能承诺、真实球场名。
- **示意内容**：图里出现虚构的时间、人数、距离、热力数据 → `META.demo=True`（页面会打「示意」角标）。产品事实以 `业务规则.md` 为准（7 天窗口、按水平匹配、距离筛选、申请 / 邀约流程等），不要编造功能。
- **不要**：真实照片、真人、别人的商标 / 吉祥物 / 球星 / 赛事标识、有版权的素材。球一律用 lib 画的。

    demo=False, concept='一句话说清画面和寓意', use='用在哪、讲哪个功能',
)

def svg():
    random.seed(21)                        # 有随机就必须定种子，重画结果才一致
    body = f'''
<defs><radialGradient id="bg21" cx="50%" cy="40%" r="85%"><stop offset="0" stop-color="#0F4A36"/><stop offset="1" stop-color="#04120C"/></radialGradient></defs>
<rect width="{W}" height="{H}" fill="url(#bg21)"/>
{tag('ENGLISH TAG')}
{headline(META['lines'], y=330, size=112, colors=(C['cream'], C['lime']))}
{ball('a', 540, 800, 200)}

    return page(body)

## lib 速查（marketing/lib.py）
- `ball(id,cx,cy,r,rot=-22,blur=0)` 写实网球；`seamdisc(cx,cy,r,rot,fill,seam,id)` 扁平球。**id 在同一张里不能重复。**
- `headline(lines,x=80,y=330,size=112,colors=(奶油,黄绿),ls=4,lh=None,anchor='start')` 多行标题；`sub(text,x,y,size,color,op,ls,anchor)` 副标题；`tag(text,x,y,color,rule)` 小标签。
- `wordmark(cy,color,sub=True)` 品牌标；`grain(op,light)` 颗粒；`persp(t,…)` 球场透视；`page(body)` 包成网页。
- **手作质感**：滤镜 `url(#rough)`（大块形状的手绘抖动）、`url(#rough2)`（细线条 / 文字的轻微抖动），套在 `<g>` 上即可；配 `grain(light=True)` 做纸感。21–24 号是例子。
- **月亮和深空**：`moon(id,cx,cy,r,seed,glow)` 写实满月（暗海、环形坑、亮纹、光晕，26–28 号用）；`space(seed,avoid=[(cx,cy,r)],ymax)` 深空渐变 + 银河 + 星点，放最底层。月亮别画成脏灰：月面要亮，光晕要冷白，天空保持深色。
- **小球表情**：`face(cx,cy,s,mood,look)` 给球画脸（mood: smile / happy / sleep；s ≈ 球半径/118），30、33–36 号用；做可爱系列（晚安、早安、纸船、秋千、热气球）时直接用。
- **文字游戏 / 拆字海报**（37 伴、38 球）：先用 Playwright 渲染单字加竖向参考线，找出部件边界（笔画常常互相咬合，没有空白列），再用折线 `clipPath`（右半边用 `clip-rule="evenodd"` 取补集）把两部分分色；别用直线切。
- **用户口味（10-29 明确反馈）**：不喜欢煽情、刻意、喊口号的文案（37「一个人，是半…」、38「球，就是求一个人」、40「隔着一张网…」被点名不喜欢，别再做这类哲理 / 拆字 / 金句）。喜欢**自然、大气、美观**的画面，像日月星辰、草木花树、山川湖海、城市万家灯火；文字只留一句**打过球的人都会心一笑的大实话**（如「今天风有点大。」「球场的灯，比我先亮。」「今晚，有人在打球。」），字小、克制，画面是主角。41–44 号是样板。
- **设计观**：不为可爱而可爱。一张只讲一个想法，要有让人会心一笑的点（拆字、术语双关、物理图），再靠构图、字体和留白撑起品位。37–40 是这个路子的样板。
- **场地质感做法**（45–48）：红土 = 渐变底 + 泥纹噪声滤镜（feTurbulence 调成暗红）+ 刷痕弧线 + 滑步痕 + 脚印；假草 = 数千根短草丝（固定种子）+ 沙粒，白线上再盖一层草丝；硬地 = 平涂蓝绿 + 白线 + 长影子（用 rotate + scale(1,k) 把站姿剪影拉成地面影子）。`url(#bl6)` `#bl14` `#bl28` `#bl60`（高斯模糊，区域已放大，**别自己写滤镜**，否则会出方块边）、`#fuzz`、`#grain`。
- **四格组图**：`marketing/four_times.py` 的 `render(surface,sid,lines,tag_text,bg,fg,rule,wry)`，surface=clay / grass / hard，同一机位四个时段（清晨 / 正午 / 傍晚 / 深夜）2×2，每格一句小毛病；新场地或新梗只改 `feats()` 和文案，61–63 号用它。
- **字标圆点是荧光黄绿**：在黄绿 / 浅色大色块上看不见，底部加一条深色条再放 `wordmark`（50、58、67 踩过）。
- **冷知识海报做法**（68–72）：先挖网球事实（只用真的，拿不准写「相传」），再用网球物件承载：球当钟面（70）、两球当 0（68）、球罐成分表（69）、球网剖面加标注线（71）、红土球印加粉笔圈（72）；画面里留 2–3 处可细看的小标注。
- **批量出图节奏**：一次 heredoc 写 3–4 个 `pNN_*.py`，`build.py --only` 一次出，Read 逐张看，只改被发现的缺陷，再统一改张数（`sed` CLAUDE.md / 进度记录.md / 本文件）、`--check`、`site.mjs`、`site.js`、提交推送、`SendUserFile` 发图。
- **角色「小毛」（10-30 定稿，用户点名「这个小毛设计得很好」= 78 号画法）：一律用 `mao3.figure3(id,cx,cy,r,pose,mood,gy=…,char='mao'|'rong')`**：36 号同款立体球 + 黑色手写细线手脚 + `face2` 的脸；**不画眉毛、睫毛、头顶的毛**；小绒 = 嫩粉立体球（`PINK`）+ 一个小蝴蝶结。场景海报（84）和设定图（78–81）都用它。**下面 v4（`mao4.py`，82–83）已弃用，仅留作记录**：v4，`marketing/mao4.py` 的 `figure4(id,cx,cy,r,pose,mood,char,gy=…)`：平面设计风纯色球（无高光、无渐变、无暗部；绒感 = 轮廓柔边（同色小半径模糊，**不是锯齿**）+ 极淡短绒纹 + 球缝几根细绒；不要外圈毛须、噪点颗粒、高光，用户都说不自然 / 疙瘩 / 像苹果；小毛头顶不要毛）、婴儿比例大眼睛（无睫毛）、嫩棉花糖粉 `PINK_P`、手脚更短；合照见 p82。**v3（78–81，`mao3.py`）球面太光滑像蛋、睫毛和比例被用户说奇怪，别再用**；以下姿势 / 笔触规则 v3、v4 通用。v3 说明：`figure3(id,cx,cy,r,pose,mood,char)`；两个角色：**小毛（男，`char='mao'`，头顶一小撮毛，嘴硬心软）/ 小绒（女，`char='rong'`，**一颗粉色的球**（`mao3.ball_c` + `PINK`）+ 奶油白小蝴蝶结 + 睫毛 + 玫瑰色腮红，话多守时；不要再画马尾、裙子）**，是好朋友；小绒用名字姿势时左右镜像（动作手在左，不和马尾打架）；合照用 dict 姿势 + `gy` 定地面线（见 p80）；：写实荧光球 + 33–36 同款脸（`mao2.face2`，眼睛用黑色）+ **只用黑色手写细线画手脚**（`pen` 双笔触 + `rough2` 抖动；手是小圆圈，脚是小椭圆球鞋，脚下一笔地面线）。**必须放浅色底**（奶油 `#FBF4E3→#F1E3C4`），黑线才看得见；浅色底字标圆点看不见，底部做深绿弧形条再放字标；标题用深绿 + `#C2410C`。pose=wave/cheer/plead/racket/wow/sorry/sleep；mood=smile/happy/cheer/wow/plead/wink/sweat/sleep；坐、抓绳等特殊姿势用 `pen/hand3/shoe3` 自己拼（见 p79）。v1（73–75 冷面脸）用户说「看起来不舒服、奇怪」，v2（76–77 黄绿粗手脚）用户说「球长手长脚奇怪」，**都别再用**。脸用 `face3`（face2 + 细眉毛 + 小绒睫毛 + 睡着的鼻泡）；细节：鞋带、求约的闪光星、歪头。口吻：陈述句、句号收尾、无感叹号。

## 角色 / 吉祥物设计方法（可复用，10-29 小毛小绒磨了 6 版才定）
1. **先问风格，再问材质**：用户要的是「正常的平面设计角色」，不是 3D 渲染。平面风 = 纯色块 + 干净线条；人没有高光，球也不要高光、渐变、暗部（加了像苹果 / 像蛋）。
2. **材质靠最少的暗示**：真实感做不好就别硬做，一个材质只留一个线索。网球绒感 = 轮廓一圈极轻的柔边 + 极淡的短绒纹（要凑近才看见）+ 球缝几根细绒。**绝不用**：外圈毛须（像刺）、噪点颗粒（疙瘩 / 砂纸）、锯齿三角毛边（锯齿感，网球不是这样）、高光反光。
3. **轮廓永远干净**：边缘要么光滑要么轻微柔化；任何「毛」都不能让剪影变成锯齿。
4. **婴儿比例**：大圆眼睛放低，嘴小成一个点，手脚短而细（黑色手绘线，小圆手、小鞋）；不要睫毛，性别靠颜色 + 一件小配饰（蝴蝶结）区分。
5. **配饰做减法**：男性角色头上不加毛 / 帽子；每个角色最多一件配饰。
6. **颜色**：粉要嫩（棉花糖粉 `#FFC6D8` 平涂），黄绿用品牌荧光黄绿；放在浅色底上让黑线、粉色都看得清。
7. **改版节奏**：每一轮只改一个变量，出图后先看大图再看缩略图；用户说「奇怪 / 不自然」时，先判断是**材质过度**还是**比例**问题，别在原方向上继续加细节，往简化方向退一步。

## 角色海报的「36 号范式」（用户 10-29 点评「无论是背景还是人物，非常好」，以后角色海报先照这个想）
36 号「早安小球」好在哪（对照 `posters/p36_good_morning.py`）：
1. **角色是场景里的一员，不是孤立的贴纸**：球像朝阳从草坡后升起，只露大半个。背景在讲故事（光芒、天空、远山），角色只负责一个动作 + 一个表情。别再把角色单独摆在空白奶油底上堆细节。
2. **背景是「渐变天空 + 几层平涂剪影」**：天空 3–4 色竖向渐变（青绿 → 灰绿 → 蜜桃 → 奶黄），放射光芒（淡奶白三角，opacity≈.16），一团大半径模糊的暖光，几朵模糊云，几只小鸟；前景 3 层深浅不同的绿色平涂山丘，最下一层最深，托住字标。层次靠颜色深浅，不靠细节。
3. **角色的脸极简**：两个深色竖椭圆眼睛 + 一个小白点高光 + 小弧线嘴 + 柔和腮红。没有睫毛、眉毛、反光、多余装饰。
4. **球的质感是「柔」的**：球身用柔和的渐变和极细的颗粒，球缝是干净的奶白带；光和场景同源（朝阳在后面），所以不显得突兀。被否的是**贴纸式的塑料高光 + 空背景**（像苹果），不是渐变本身。
5. **主色关系**：球是整张最亮的点（荧光黄绿），背景用青绿 / 暖色衬它；标题深绿 + `#C2410C`，底部深色条放字标。
6. **一张一个想法**：这一张只讲「早上也有球」。
**球身两种画法**：场景海报（36、84）用 `figure4(..., ball_style='soft')` = 36 号同款立体球（渐变 + 细颗粒 + 边缘暗角 + 干净球缝），角色有体积感；浅色空白底的设定图（82、83）才用默认 `'flat'` 平涂。用户 10-29 评 84 首版「平面的，没有 36 号立体」，场景里的角色必须立体。
**以后做角色（小毛 / 小绒）新海报**：先选一个有画面感的时刻（日出、傍晚球场、雨后、夜里的泛光灯），用上面的方法搭场景，角色按 36 号的脸画（可保留小毛小绒的黑色细线手脚，但脸和球身用 36 号的画法），再出图；不要先画角色再找背景。

## App 里的空状态 / 提示图标 / 文案（11-04 用户连称「非常棒」，以后照这套做）
做空状态、报错、加载、通知、成功提示、分享贴纸之前，先读 `marketing/icons/README.md`（36 个小毛图标 + 文案表 + 方案图）。要点：
1. **一句话公式**：空和错的时候不说「没有」，说一句只有打网球的人才懂的话（让人会心一笑）+ 一句副句递出下一步。双关优先：发球=发布球局、出界=球局不存在、断线=拍线 / 网络、开罐=更新、热身=加载。文案规则同海报：陈述句、句号收尾、无感叹号、不说教、不「A，才B」。
2. **图标画法**：`marketing/icons/helpers.py`（生成脚本共用）——小毛 = `figure3`（立体球 + `face2` 脸）+ **流畅单笔细线手脚**（覆盖 `mao3.pen` 为单笔、去掉 `rough2` 抖动；B 方案被说「太像手写不流畅」）；viewBox 220×220、球半径 42、地面 y=198；一个动作 + 一个道具，极简。
3. **心理学**：空状态最大风险是用户觉得「这个 App 没人」→ 要显示社区是活的、给最小下一步、降低发局成本、留住回来的理由。
4. **筛选后没有球局 = 自适应，不写死一句话**：回显用户条件 → 逐项单独放宽一档并数球局（距离 5→10→20 km；水平只放半档；类型 / 标签→不限；日期→最近有球的日子）→ 只推真有球局的前两项（距离→日期→类型→水平）→ 单项都 0 才试两项 → 仍 0 才「发球 + 发一局 + 通知我」。有建议时「发一局」是次按钮；小毛状态跟着情形走（放大镜 / 一摊手 / 发球）；**没有真实数据的数字（想打人数、附近有人）不显示**。
5. **文案池**：同一场景 3–5 句，按时段 / 星期 / 天气 / 里程碑挑一句，别让用户天天看同一个笑话。
6. **舞台风（参考世界优秀空白页，用户 11-04 要求）**：`marketing/icons/舞台风/`——圆形舞台 + 鼠尾草绿单色调 + 小毛球是唯一亮点 + 漂浮小几何 + 一个叙事小惊喜 + 物体即隐喻（邮箱 / 放大镜 / 路牌 / 球罐 / 日夜开关）。比 36 个单体图标更精致，作为 App 空状态的首选画风；单体图标可作小尺寸备用。
7. **接入 App 时**：只改 `src/`（网页端 + 手机端有两处重复的空状态代码，先抽共用函数）；用户明确说过的要求先写成测试（断言 DOM，不只断言内存）；动效用 CSS，不用 GIF。

## 经验和坑
- 球落在地面要加阴影椭圆（`bl14`），光线方向统一（左上亮、右下暗）。
- 全角逗号后面有一段空白：标题折行用 `lines` 分两行，不要在一行里放逗号再接内容。
- 浅色底 wordmark 颜色 `#0B3B2A`；深绿地面上不要用深色字（6 号清晨球场就踩过）。
- 球和文字别叠在一起：先算好球的上沿 / 下沿再定标题和品牌标位置（1 号、3 号都返工过）。
- 圆环、拱形等几何图形先算坐标再写，别靠试；画完用 `--only` 看图，不要靠想象。
- webp 大图只有 30–80KB，别担心体积；颗粒效果在缩略图里基本看不出，不用调。

## 还没做的方向（想不到做什么时从这里挑；更全的清单在 品味手册.md §八）
- **网球冷知识 × 小心思**（用户最近最认可）：平分后连赢两分、拍线磅数、单双打边线、换边 90 秒、发球前拍球、握把带越缠越厚、开新球罐「嘶」一声。
- **断线系列**：57 之后可做换线单上张力越写越高、「拍线是消耗品」。
- **已做**：月亮 / 深空 25–28，可爱 30–36，风景 41–44，场地 45–48 + 四时段 61–63，小毛病 49–60，天气 54/64/65，冷知识 68–72；不好的 37/38/40/66/67 别再做同类。
- **新手友好**：「新手也能约。」水平分档、同水平匹配，降低门槛。
- **女生 / 安全感**：屏蔽、隐私（`隐私清单.md`），文案克制，不渲染焦虑。
- **墨尔本日常**：电车站、周末市集、海边球场、雨天改期。
- **邀约**：「约 TA 打球」一天最多 3 个。
- **悉尼扩展**：`地区扩展设计.md`，上线再做。
- **澳网季**（1 月）：只用通用元素，**不用赛事标识**。
- **其他尺寸**：小红书 3:4（1080×1440）、竖屏故事 9:16、公众号头图 2.35:1 **还没支持**——需要时：`lib.set_size()` + build.py 按 `META.size` 渲染 + site.mjs 物料页的缩略图比例，三处各改一点；别用裁剪 4:5 凑数（标题和品牌标会被切）。
