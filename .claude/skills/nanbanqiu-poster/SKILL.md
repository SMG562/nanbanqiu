成品都在预览站「宣传物料」页（/materials.html，手机能看、能存大图），推送到 main 自动更新。

## 流程
1. `python3 marketing/build.py --list`：看已有海报的编号 · 标题 · 风格 · 创意，**不重复**；**编号先查别的分支**（`git ls-remote` + 各分支 `marketing/posters/`，多个对话会同时出图，11-08 撞过 85–88）；想不到方向就看文末「还没做的方向」。
2. 新建 `marketing/posters/pNN_slug.py`（NN 接着最大编号，slug 用连字符，文件名里换成下划线），照下面的模板写 `META` 和 `svg()`。
2b. **出图前确认装了思源字体**：`fc-list :lang=zh | grep -c Noto`，为 0 就 `apt-get install -y fonts-noto-cjk fonts-noto-cjk-extra`（11-08 云端容器没装，110–159 首版全用了文泉驿替代字体，已重出）；python 的 playwright 版本要和 /opt/pw-browsers 里的浏览器对上（`pip install playwright==1.63.0`）。
3. `python3 marketing/build.py --only NN`：出 `img/NN-slug.webp`（1080×1350）、`thumb/`（360×450），登记 `posters.json`，并**自动检查文字**（出画布 / 离边太近 / 互相压住；旋转组里的文字可能误报）。
4. 看图：Read `marketing/img/NN-slug.webp`（一张约 2k token）。多张对比用 `--sheet /tmp/s.jpg`（缩略总览，一次读完）。改数字或文案后重跑 `--only NN`，不要整文件重写。
5. 收尾：`node tests/frontend/site.js`（站点测试，约 15 秒，会核对 posters.json、源文件、图片是否对得上）→ 提交（`marketing/` 整个目录：源文件、posters.json、img、thumb）→ 推送。
6. 给用户高清大图：`python3 marketing/build.py --only NN --hires <用户电脑文件夹>/宣传物料`（PNG 1620×2025，不进仓库，.gitignore 已忽略 png）。电脑文件夹要先用 device_request_folder_access 接上。
7. 进度记录不用为每张海报单独写；posters.json 就是清单。只有品牌规则或流程变了才改本文件。

## 品牌规则（细则在 `设计总纲.md`，这里只留最常用的）
- **南伴绿大面积 + 荧光黄绿只给球**；光亮饱满；一张一件事；人小天地大；学方法不学外观。
- **颜色**（lib.C）：深绿 deep `#0B3B2A`、green `#176B4D`、mid `#0E5139`；荧光黄绿 lime `#C6EA3D`；奶油 cream `#F7EBD6`、paper `#F3E6CC`；复古系列才用 orange `#E8643C` / amber `#F2B134`；咖啡色 `#B0582F`。系列辅助色见总纲 §三。
- **字体**：标题衬线 `SERIF`（Noto Serif CJK，700/900），其余无衬线 `SANS`；英文小标签字距 5–9、全大写。
- **版式**（1080×1350）：左右边距 64–84；标题 56–78 号（少字主视觉 96–112）；底部 y≈1190 起是落款带（深色底上放 `wordmark()` 或小落款，圆点才看得见）；留白要足。
- **文案**：一两句，陈述句，句号收尾，全角标点，不用感叹号，不讲道理。
- **示意内容**：虚构的时间、人数、球场名 → `META.demo=True`。产品事实以 `业务规则.md` 为准。
- **不要**：真实照片、真人、别人的商标 / 台标 / 吉祥物 / 球星 / 赛事标识 / 片名 / 歌词、有版权的素材。球一律用 lib 画的。

## 模板
```python
from lib import *  # 品牌常量和绘图工具

META = dict(
    id=21, slug='my-idea', title='标题', lines=['前半句，', '后半句。'],
    style=['插画'], tone='深色',           # tone: 深色 / 浅色 / 亮色；style 可多个，例：写实光影 插画 信息图 排版 极简 双关 复古 地域梗 图标构图
    demo=False, concept='一句话说清画面和寓意', use='用在哪、讲哪个功能',
)

def svg():
    random.seed(21)                        # 有随机就必须定种子，重画结果才一致
    body = f'''
<defs><radialGradient id="bg21" cx="50%" cy="40%" r="85%"><stop offset="0" stop-color="#0F4A36"/><stop offset="1" stop-color="#04120C"/></radialGradient></defs>
<rect width="{W}" height="{H}" fill="url(#bg21)"/>
{tag('ENGLISH TAG')}
{headline(META['lines'], y=330, size=112, colors=(C['cream'], C['lime']))}
{ball('a', 540, 800, 200)}
{wordmark(1268, '#fff', sub=False)}
{grain(.18)}'''
    return page(body)
```

## lib 速查（marketing/lib.py）
- `ball(id,cx,cy,r,rot=-22,blur=0)` 写实网球；`seamdisc(cx,cy,r,rot,fill,seam,id)` 扁平球。**id 在同一张里不能重复。**
- `headline(lines,x=80,y=330,size=112,colors=(奶油,黄绿),ls=4,lh=None,anchor='start')` 多行标题；`sub(text,x,y,size,color,op,ls,anchor)` 副标题；`tag(text,x,y,color,rule)` 小标签。
- `wordmark(cy,color,sub=True)` 品牌标；`grain(op,light)` 颗粒；`persp(t,…)` 球场透视；`page(body)` 包成网页。
- **手作质感**：滤镜 `url(#rough)`（大块形状的手绘抖动）、`url(#rough2)`（细线条 / 文字的轻微抖动），套在 `<g>` 上即可；配 `grain(light=True)` 做纸感。21–24 号是例子。
- **月亮和深空**：`moon(id,cx,cy,r,seed,glow)` 写实满月（暗海、环形坑、亮纹、光晕，26–28 号用）；`space(seed,avoid=[(cx,cy,r)],ymax)` 深空渐变 + 银河 + 星点，放最底层。月亮别画成脏灰：月面要亮，光晕要冷白，天空保持深色。
- **小球表情**：`face(cx,cy,s,mood,look)` 给球画脸（mood: smile / happy / sleep；s ≈ 球半径/118），30、33–36 号用；做可爱系列（晚安、早安、纸船、秋千、热气球）时直接用。
- **文字游戏 / 拆字海报**（37 伴、38 球）：先用 Playwright 渲染单字加竖向参考线，找出部件边界（笔画常常互相咬合，没有空白列），再用折线 `clipPath`（右半边用 `clip-rule="evenodd"` 取补集）把两部分分色；别用直线切。
- **场地质感做法**（45–48）：红土 = 渐变底 + 泥纹噪声滤镜（feTurbulence 调成暗红）+ 刷痕弧线 + 滑步痕 + 脚印；假草 = 数千根短草丝（固定种子）+ 沙粒，白线上再盖一层草丝；硬地 = 平涂蓝绿 + 白线 + 长影子（用 rotate + scale(1,k) 把站姿剪影拉成地面影子）。`url(#bl6)` `#bl14` `#bl28` `#bl60`（高斯模糊，区域已放大，**别自己写滤镜**，否则会出方块边）、`#fuzz`、`#grain`。
- **四格组图**：`marketing/four_times.py` 的 `render(surface,sid,lines,tag_text,bg,fg,rule,wry)`，surface=clay / grass / hard，同一机位四个时段（清晨 / 正午 / 傍晚 / 深夜）2×2，每格一句小毛病；新场地或新梗只改 `feats()` 和文案，61–63 号用它。
- **字标圆点是荧光黄绿**：在黄绿 / 浅色大色块上看不见，底部加一条深色条再放 `wordmark`（50、58、67 踩过）。
- **冷知识海报做法**（68–72）：先挖网球事实（只用真的，拿不准写「相传」），再用网球物件承载：球当钟面（70）、两球当 0（68）、球罐成分表（69）、球网剖面加标注线（71）、红土球印加粉笔圈（72）；画面里留 2–3 处可细看的小标注。
- **批量出图节奏**：一次 heredoc 写 3–4 个 `pNN_*.py`，`build.py --only` 一次出，Read 逐张看，只改被发现的缺陷，再统一改张数（`sed` CLAUDE.md / 进度记录.md / 本文件）、`--check`、`site.mjs`、`site.js`、提交推送、`SendUserFile` 发图。
- **角色小毛 / 小绒**：一律 `mao3.figure3(...)`，画法、姿势、禁忌见 `角色_小毛小绒.md`。
- **画风工具**（`lin.py` 林风眠、`song.py` 宋画、`han.py` 汉风、`textbook.py` 课本、`poet.py` 诗人、`wide.py` 宽幅、`candy.py` 开学季……）：用途和结论见 `风格库.md`，**学方法不学题材**，不落真实画家的名字和印。
- 常量 `W H SERIF SANS C`，以及 `math` `random` 已导入。

## App 里的空状态 / 提示图标 / 文案（11-04 用户连称「非常棒」，以后照这套做）
做空状态、报错、加载、通知、成功提示、分享贴纸之前，先读 `marketing/icons/README.md`（36 个小毛图标 + 文案表 + 方案图）。要点：
1. **一句话公式**：空和错的时候不说「没有」，说一句只有打网球的人才懂的话（让人会心一笑）+ 一句副句递出下一步。双关优先：发球=发布球局、出界=球局不存在、断线=拍线 / 网络、开罐=更新、热身=加载。文案规则同海报：陈述句、句号收尾、无感叹号、不说教、不「A，才B」。
2. **图标画法**：`marketing/icons/helpers.py`（生成脚本共用）——小毛 = `figure3`（立体球 + `face2` 脸）+ **流畅单笔细线手脚**（覆盖 `mao3.pen` 为单笔、去掉 `rough2` 抖动；B 方案被说「太像手写不流畅」）；viewBox 220×220、球半径 42、地面 y=198；一个动作 + 一个道具，极简。
3. **心理学**：空状态最大风险是用户觉得「这个 App 没人」→ 要显示社区是活的、给最小下一步、降低发局成本、留住回来的理由。
4. **筛选后没有球局 = 自适应，不写死一句话**：回显用户条件 → 逐项单独放宽一档并数球局（距离 5→10→20 km；水平只放半档；类型 / 标签→不限；日期→最近有球的日子）→ 只推真有球局的前两项（距离→日期→类型→水平）→ 单项都 0 才试两项 → 仍 0 才「发球 + 发一局 + 通知我」。有建议时「发一局」是次按钮；小毛状态跟着情形走（放大镜 / 一摊手 / 发球）；**没有真实数据的数字（想打人数、附近有人）不显示**。
5. **文案池**：同一场景 3–5 句，按时段 / 星期 / 天气 / 里程碑挑一句，别让用户天天看同一个笑话。
6. **舞台风（参考世界优秀空白页，用户 11-04 要求）**：`marketing/icons/舞台风/`——圆形舞台 + 鼠尾草绿单色调 + 小毛球是唯一亮点 + 漂浮小几何 + 一个叙事小惊喜 + 物体即隐喻（邮箱 / 放大镜 / 路牌 / 球罐 / 日夜开关）。比 36 个单体图标更精致，作为 App 空状态的首选画风；单体图标可作小尺寸备用。
7. **接入 App 时**：只改 `src/`（网页端 + 手机端有两处重复的空状态代码，先抽共用函数）；用户明确说过的要求先写成测试（断言 DOM，不只断言内存）；动效用 CSS，不用 GIF。

## 经验和坑
- 球落在地面要加阴影椭圆（`bl14`），光线方向统一（左上亮、右下暗）。
- 全角逗号后面有一段空白：标题折行用 `lines` 分两行，不要在一行里放逗号再接内容。
- 浅色底 wordmark 颜色 `#0B3B2A`；深绿地面上不要用深色字（6 号清晨球场就踩过）。
- 球和文字别叠在一起：先算好球的上沿 / 下沿再定标题和品牌标位置（1 号、3 号都返工过）。
- 圆环、拱形等几何图形先算坐标再写，别靠试；画完用 `--only` 看图，不要靠想象。
- webp 大图只有 30–80KB，别担心体积；颗粒效果在缩略图里基本看不出，不用调。
