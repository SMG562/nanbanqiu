# 南伴球标志系统 v1.0（11-10）

规范页：`guide.html`（`python3 marketing/brand/guide.py` 生成）。成品：`svg/`，31 个，全部转曲。

- **符号**：一大一小两颗球（r₂/r₁ = 0.635），小球外留白环 3.2 切进大球；几何与 `icons/icon.svg` 同一套坐标。标志一律平涂单色，球缝和留白环镂空；立体球只用于 App 图标和插画。
- **组合**（h = 中文字标墨迹高，x = 小球直径）：
  - 横式：符号高 1.25 h，墨迹中线对齐，间距 0.75 x，字距 0.16 em；双行版英文与中文同宽。
  - 竖式：符号高 1.9 h，到字 0.55 h，字距 0.24 em，英文字高 0.22 h、与中文同宽。
  - 签名式（海报落款）：字距 0.32 em，符号高 0.55 h，中心对准「伴」「球」字缝，底距字顶 0.12 h。
  - 字标、符号单独使用。
- **配色**：黄绿只放深底；浅底 / 黄绿底整个标志用深绿单色；另有黑色单色、反白。
- **安全区** 1 x；**最小尺寸** 符号 24 px（以下用 `mark-simple`）、横式宽 96 px、竖式 72 px、签名式 120 px。
- **海报落款**：签名式居中，宽 = 画布宽 22%，底边距 = 画布高 4.5%（1080×1350：宽 240、字底 y=1290）。
- 字体：字标思源黑体 Bold（转曲，轮廓在 `glyphs.json`），标题思源宋体，英文 Inter SemiBold，均 OFL。
- 改标志只改 `logo.py` 常量，再跑 `logo.py`、`guide.py`。
