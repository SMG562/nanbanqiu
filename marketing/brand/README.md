# 南伴球标志系统（v1.0，11-10 定稿）

> 出图 / 做周边只需要读 §3「选哪个标志」和 §4「怎么调用」。§1–2 是来龙去脉，改版前再读。
> 看图：`guide.html`（主标志规范）、`variants.html`（衍生 / 周边）。成品：`svg/`（53 个，全部转曲）。

## 1. 设计理念
- **两颗球 = 两个人 = 「伴」**。约球的最小单位是两个人；一大一小，不必一样强；靠在一起，说明约上了。
- **留白环 = 分寸**。小球外一圈空隙切进大球：陌生人约球，挨得近，也各有空间。
- **一来一回**。两条球缝转向相反（−22° / +28°）；签名式里小双球在「伴」「球」字缝上方，是发球前的那一抛。
- **点式 = 放松版**（用户 11-10 点名喜欢）：两颗纯色球拉开，去掉球缝。主标志管“认得出”，衍生管“想带走”。
- 调性：克制、大气、球是唯一亮点（同海报口味，见 `.claude/skills/nanbanqiu-poster/品味手册.md`）。

## 2. 设计思路与决策（为什么这样，不要轻易推翻）
| 决定 | 理由 / 被否掉的做法 |
|---|---|
| 几何沿用 App 图标（100 网格：大球 (40,40) r26、小球 (67,66) r16.5、留白环 3.2） | 标志和图标必须同一对球；r₂/r₁ = 0.635 近黄金比 |
| 标志一律平涂单色，球缝和留白环镂空 | 任何颜色、丝印、刺绣、刻章都成立。立体渐变球只用于 App 图标和插画 |
| 浅底 / 黄绿底整个标志用深绿单色 | 黄绿在奶油底对比度 1.17:1，看不见（海报 50/58/67 踩过）；深底上 9.1:1 |
| 字标 = 思源黑体 Bold 转曲（`glyphs.json`），不手绘 | 现成、OFL 可商用、稳定；以后请字体设计师精修只换 `glyphs.json` |
| 所有比例以字墨迹高 h、小球直径 x 为单位 | 按墨迹对齐，不按字身框；缩放不变形 |
| 横式符号 1.25 h | 圆形视觉上比方块字小，放大 25% 才等重 |
| 三种字距：横式 0.16 em / 竖式 0.24 em / 签名式 0.32 em | 横式要紧凑成一体；签名式宽字距是用户原图的气质 |
| 点式间距 6.4u（两倍留白环 ≈ r₁/4） | 再近粘成一团，再远散成两颗不相干的点 |
| 日常海报落款 = 点式签名；带球缝的签名式留给正式场合 | 用户原图就是点式；日常物料要轻松 |
| 点式签名·居中版按「外框中心与面积重心各取一半」对齐 | 纯外框居中点组看着偏左（大球在左），纯重心居中又偏右（11-10 三版对比定） |
| 英文名 = 连写拼音 **Nanbanqiu**（标志内全大写 NANBANQIU），不拆、不意译 | 与域名 nanbanqiu.app、标志一致；拆成 Nan Ban Qiu 会让英文读者先看到 ban（禁止），也像一句话不像品牌；意译名（Tennis Mate 类）太通用、难注册商标，等做非华人用户再议 |
| 旧 `lib.wordmark()` 停用于新海报 | 文字没转曲；`letter-spacing` + `text-anchor=middle` 让整体左偏半个字距（约 7 px） |

## 2b. 英文名用法（11-10 定）
- 正文 / 商店页：**Nanbanqiu**（只首字母大写，不写 NanBanQiu、Nan Ban Qiu）；标志内：**NANBANQIU**。
- 英文说明配一句：**Nanbanqiu · Tennis partners in Melbourne**（商店副标题、名片背面、英文页面；悉尼上线后换城市名）。
- 读音（关于页一行）：**Nanbanqiu (nahn-bahn-chee-oh)**。

## 3. 选哪个标志（直接按这张表说 / 用）
| 场景 | kind | on（底色） | 尺寸 |
|---|---|---|---|
| **日常海报落款**（1080×1350 / 3:4 / 9:16） | `sig-dots` | 跟着底色 | 宽 = 画布宽 22%，字底距底 4.5% 高（默认参数就是） |
| 居中构图的封面、周边正面、对称版式落款 | `sig-dots-c`（点式签名·居中：两点在字标正中 / 「伴」上方） | 跟着底色 | 同上 |
| 正式海报、公告、合作物料落款 | `main-sig` | 同上 | 同上 |
| 海报封面 / 启动页 / 竖长空间 | `main-v` | | 宽 ≈ 画布 30–40% |
| App 顶栏、网页导航、文件抬头 | `main-h` | dark | 高 26 px（App）|
| 对外合作、英文页面、名片背面 | `main-h-en` | | |
| App 图标、头像、网站图标 | `mark`（< 24 px 用 `mark-simple`） | | 头像：外框高 = 圆直径 52% |
| T 恤胸口、帽子、别针 | `dots` | dark | 胸口宽 3.5 cm，帽前 5–6 cm |
| 吊牌、袋子侧面、周边印字 | `h-dots` / `sig-dots` | | |
| 球拍包、横幅、邮件签名（长条） | `rally` | | |
| 加载动画、段落分隔、文章结尾 | `bounce` | | |
| 压纹、皮标、单线刺绣、激光雕刻 | `outline` | | |
| 毛巾、竖幅、球包侧面 | `vertical` | | |
| 避震器、方形贴纸、盖章 | `seal`（自带底） | dark→深绿章 / 其他→黄绿章 | |
| 圆形贴纸、刺绣章、杯垫 | `badge`（自带底） | dark→深绿 / 其他→奶油 | |
| 帆布袋、包装纸、毛巾边、App 空白背景 | 图案：`variants.pattern(bg, ball, w, h, cell, id)` | | App 背景降到 6% 透明度 |

规则：一个画面 / 一件周边只出现一次标志、只用一种变体；App 图标、商店页、合作文件只用主标志（`main-*` / `mark`）。
**on**：`dark`（深绿 / 深色照片）· `light`（奶油 / 白 / 亮色照片）· `lime`（黄绿底）· `black`（白底黑色单色印刷）· `white`（黑底反白）。浅色底会自动变深绿单色，不用自己判断。
**安全区** 1 x（小球直径）；**最小尺寸** 符号 24 px、横式宽 96 px、竖式 72 px、签名式 120 px。
**禁止**：拉伸、旋转、换品牌外颜色、加描边 / 投影 / 渐变、浅底用黄绿球、调换大小球、用别的字体重打、放在杂乱背景上（先压一块深色）。

## 4. 怎么调用
- **海报**（`marketing/posters/pNN_*.py`，已 `from lib import *`）：
  `{logo()}` = 日常落款（深底）；`{logo(on='light')}` 浅底；`{logo('main-v', 'dark', 540, 600, 380, 'center')}` 封面。
  签名：`logo(kind, on, x, y, w, anchor)`，anchor = bottom（默认，底边中点）/ center / top / topleft。
- **其他 Python**：`sys.path` 加 `marketing/brand` 后 `import api; api.render(kind, on)` → `(svg片段, 宽, 高)`。
- **设计软件 / 发给厂家**：直接用 `svg/` 里的文件。命名 `nanbanqiu-<组合>-<配色>.svg`；衍生是 `nanbanqiu-variant-<名>-<配色>.svg`。SVG 透明底，配色名说明该放什么底。
- **App 里（还没接）**：`src/` 里 `#logo` symbol 目前是立体图标版；顶栏要换成 `main-h` 平涂版时走小 PR，只改 `src/`。

## 6. 迭代方法
1. 改什么都只改 `logo.py` / `variants.py` 的常量或函数 → `python3 marketing/brand/logo.py` → 截图看（`guide.html` 用 Playwright 全页截图，切 3–4 段读）→ 提交 `marketing/brand/` 整个目录。
2. 新变体：`variants.py` 写函数（几何必须用 R1/R2/ANG，保持认得出）→ `api.KINDS` 登记 → `build()` 文件表加深 / 浅两版 → `page()` 的 fams 加一格 → 本文件 §3 表加一行。
3. 要用新字：`glyphs.json` 没有的字要重新导出（fontTools 从 Google Fonts 子集取，`wght` 实例化，SVGPathPen）。
4. 改版先写清「改了哪个决定、为什么」到 §2，再动代码。用户点评原话记到 §7。
5. 改完规范页要重新发布 Artifact（同一个链接）。
