# 小毛空状态 / 提示图标（12 个）

设计思路（11-04 用户点评「这个思路非常好」）：**空和错的时候，不说「没有」，说一句只有打网球的人才懂的话，让人会心一笑，顺手把下一步递给他。**

- 图：小毛一个动作，黑色**流畅单笔细线**（不用 `pen` 的重影 / `rough2` 抖动）、立体球、脸极简。
- 文案：一句主句（陈述句、句号收尾、无感叹号、不说教）+ 一句副句（给出下一步）。
- 能用网球双关就用双关：发球 = 发布球局、出界 = 球局不存在、断线 = 拍线 / 网络。

## 备选与第三批（11-04）
- `备选/`：没球局的另外三种说法（我才没在等 / 热身做完了 / 场地我先替你占着）+ 9 个新场景。
- `第三批/`：墨尔本天气（带伞也带防晒 / 今天 38 度 / 今天风有点大）、时段（清晨 / 周六空着）、里程碑（第一局 / 手感来了 / 老球友）、爽约和改期的温柔说法、调拍线加载、分享贴纸。
- `动效演示.gif`：加载颠球、摇铃、吹口哨三个动起来的样子（接入 App 时用 CSS 动画，不用 GIF）。
- 文案池思路：同一个场景放 3–5 句，按时段 / 星期 / 天气 / 用户里程碑挑一句，用户不会天天看到同一个笑话。

## 「某天还没有球局」六个方案（11-04）
见 `某天没球局_六个方案.png`。A 虚线球局卡（填空心理）/ B 我也想打（低成本表态，要后端存「想打」）/ C 邻近日子（不留死胡同，要查邻近日球局数）/ D 照老样子（默认值，要读用户上一局）/ E 会心一笑（纯情绪，零数据）/ F 替你守着（订阅提醒，要后端存订阅）。
推荐叠加：小毛图标 + 一句会心话（E）→ 主按钮「我来发」（D 预填）→ 次要「有球局通知我」（F）→ 文字链「周六有 5 局」（C，邻近日有球时才出现）。B 数据够了再上。

## 「筛选条件下附近没有球局」自适应设计（11-04）
见 `筛选后没球局_自适应设计.png`。规则：回显条件 → 逐项单独放宽一档并数球局 → 只推有球的前两项（距离 → 日期 → 类型 → 水平；水平只放宽一档）→ 单项都 0 才试两项 → 仍 0 才走「发球 + 发一局 + 通知我」。有建议时「发一局」是次按钮；不造假数字。

## 舞台风（11-04，吸收世界优秀空白页的做法）
`舞台风/` + `舞台风总览.png`，生成：`gen_stage_scenes.py`（公共件在 `gen_stage_lib.py`）。参考的空白页共同点，已内化为规则：
1. **一个主色调 + 一个强调色**：整体低饱和鼠尾草绿（雨天换灰蓝），只有小毛那颗荧光黄绿球 + 一点橙（旗子 / 伞 / 小圆点）是亮点。
2. **圆形小舞台**：圆里有天空、两层山丘、小树，人物 / 道具可以探出圆外；脚下一层浅地面。
3. **漂浮的小几何**（空心圆、加号、波浪线、小方块、一点橙）撒在圆外，让画面有呼吸感。
4. **一个叙事小惊喜**：小毛从邮箱里探头、躲在山后偷看放大镜、球拍当天线断了线、球变成彗星飞向问号星球。
5. **物体即隐喻**：邮箱 = 消息、放大镜 = 搜索、路牌 = 登录引路、球罐塞满 = 约满、日 / 夜开关 = 时段（球是太阳）。
6. 线条克制：小毛的手脚仍是黑色细线，场景里的线用同色系灰绿，不抢戏。
